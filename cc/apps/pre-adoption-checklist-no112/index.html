# 🎁 導入前チェックシート

MiniMax M3・Qwen3.8-MaxをClaude Codeに導入する前に、確認しておきたい5つのステップをまとめました。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 上から順に□項目をチェックし、YESの行動に従って進めてください。

```text
【導入前チェックシート】

■ ステップ1: 自分のタスクに近いベンチマークを確認する
□ 単純作業(定型コード生成・雛形量産)が中心か
→ YES: MiniMax M3・Qwen3.8-Maxへの切替候補にしてよい
□ 大規模改修・複雑な設計判断が中心か
→ YES: SWE-bench Proではまだ Claude Opus/Fable が優位。無理に切り替えない
指示例: 「直近1週間でClaude Codeに依頼したタスクを、単純作業/複雑な改修に分類して」

■ ステップ2: 価格差が見合うか計算する
□ 月間のトークン利用量を把握しているか(不明ならステップ2は一旦保留)
→ YES: 「コスト削減シミュレーションシート」で概算削減額を出す
□ 削減額が導入・検証の手間に見合う規模か
→ YES: ステップ3へ進む

■ ステップ3: ライセンス・利用規約を確認する
□ 商用利用が許可されたライセンスか、各社の公式ドキュメントで確認したか
→ YES: ステップ4へ進む
→ NO: 導入を保留し、確認が取れるまで待つ
指示例: 「MiniMax M3とQwen3.8-Maxの商用利用条件を、公式ドキュメントのURLつきで整理して」

■ ステップ4: 背景にある紛争を理解した上で判断する
□ Anthropicとの蒸留攻撃疑惑が係争中であることを理解しているか
→ YES: 自己責任の範囲で導入を判断する
□ 会社としての利用可否を確認する必要があるか(セキュリティ・法務部門があるチーム等)
→ YES: 導入前に社内確認を取る

■ ステップ5: 実運用の癖を先に把握しておく
□ MiniMax M3使用時のコンテキスト表示バグ(200K表示問題)を知っているか
→ YES: CLAUDE_CODE_AUTO_COMPACT_WINDOW設定を先に適用しておく
□ うまくいかなかったときにOpusへ戻す設定を用意しているか
→ YES: 「接続設定コピペ集」の切り戻し設定を手元に用意してから導入する
```

**ポイント**: 全ステップがYESになってから本番導入する必要はありません。まずは低リスクなタスクから小さく試すのが安全です。
