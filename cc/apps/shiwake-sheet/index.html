手元の仕事を1つ思い浮かべて、上から順に答えてください。 どこかで「YES」になったら、そこで判定が確定します。

001ステップ1：まず、その仕事の形を見る
□ 手順もゴールも決まっていて、あとは実行するだけか
  → YES: 9割側。無料のGrokで足りる。指示文を1本書いて渡す
□ 毎回ほぼ同じ形で、月に3回以上くり返しているか
  → YES: 9割側。Automationsで自動化する候補。時間で動く設定なら0円
□ 出力がWord・スライド・表計算・PDFのどれかで完結するか
  → YES: 9割側。Skillsが最初から入っているので追加ツールは不要
002ステップ2：AIが動き続ける時間を見る
□ 1回の依頼で、AIが30分以上ひとりで作業し続ける必要があるか
  → YES: 1割側の候補。ステップ3へ進む
□ 途中で何度も自分で判断を入れられる（止めて確認できる）か
  → YES: 9割側。区切って渡せば安いモデルで足りる
□ 失敗しても、やり直しのコストが小さいか
  → YES: 9割側。速くて安い方を選ぶ
003ステップ3：難しさの種類を見分ける
□ 前例のない問題で、解き方そのものを探す必要があるか
  → YES: 1割側。Claude系の有料プランを検討する
□ パソコンの操作そのもの（画面を見て、押して、確認する）を任せたいか
  → YES: 1割側。この用途は差が大きい
□ 100を超える手順を、人が見ていない間に走らせ続けるか
  → YES: 1割側。長時間の安定性が効いてくる
□ 上のどれにも当てはまらない
  → YES: 9割側。まず0円で試して、足りなければ上げる
004ステップ4：判定が出たあとにやること
□ 9割側だった
  → YES: 無料アカウントを作り、その仕事をそのまま1つ渡してみる
  指示例: この作業の手順を説明します。同じことをやってください。分からない前提があれば、作業前に質問してください。
□ 1割側だった
  → YES: いきなり有料に切り替えず、まず無料で1回やらせて、どこで失敗するかを見る
  指示例: この作業を最後までやってみてください。途中で判断に迷った箇所は、勝手に決めずに一覧にして報告してください。
□ 判定が半々で決まらない
  → YES: 仕事を2つに割る。決まっている部分と、考える必要がある部分に分ける
  指示例: この作業を「手順が決まっている部分」と「判断が必要な部分」に分けて、それぞれ何をするか整理してください。
005ステップ5：1週間後に見直す
□ 無料のまま回せたか
  → YES: その仕事は9割側で確定。同じ形の仕事も無料側に寄せる
□ 検索の回数制限で止まったか
  → YES: 指示を1回にまとめる工夫をする。それでも足りなければ有料を検討
□ 出力の質が足りなかったか
  → YES: 指示文の問題か、モデルの問題かを切り分ける
  指示例: さきほどの出力で不足していた点を挙げます。指示の書き方で改善できるか、それともモデルの限界か、判断して教えてください。
