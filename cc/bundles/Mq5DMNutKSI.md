# 🎁 導入前チェックリスト＋できないこと7カ条

Workspace Studioを本格導入する前に確認すべき項目と、公式には書かれていない「できないこと」7つをまとめたチェックリストです。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 導入検討〜本番投入の各段階で、上から順にチェックしてください。

```text
【Workspace Studio 導入前チェックリスト＋できないこと7カ条】

■ ステップ1：そもそも使える環境か確認する
□ 独自ドメインのGoogle Workspace有料プラン（Business Starter以上）に加入しているか
  → NO: 個人の無料Gmailアカウントでは利用できません。まず加入を検討
□ 自分のGoogleアカウントの言語設定は日本語になっているか
  → YES: 2026年5月7日以降、UI・自然言語プロンプトとも自動で日本語表示されます（管理者設定は不要）

■ ステップ2：やりたいことが「できないこと7カ条」に当てはまらないか確認する
□ ①組織図（Directory）を見て上司に自動振り分けしたい
  → 非対応。承認ルーティングは手動設計が必要
□ ②外部システム（Webhook／CRM／決済等）からフローを起動したい
  → 非対応。トリガーはGoogle Workspace内のイベントに限定される
□ ③スプレッドシートの行を1件ずつ回すループ処理をしたい
  → 非対応。反復処理が必要な業務は別ツールを検討
□ ④メールを自動送信・自動転送・委任管理したい
  → 非対応。対応範囲は「返信の下書き作成」まで
□ ⑤他ユーザーにタスクを割り当てたい
  → 非対応。タスク作成は実行者本人向けのみ
□ ⑥テンプレートからPDF生成・複数文書のマージをしたい
  → 非対応。動的データ入りのGoogle Doc生成までが対応範囲
□ ⑦カレンダー予定にGoogle Meetリンクを確実に自動付与したい
  → 不安定。予定作成はできるがMeetリンクが付かないことがあるため、重要な会議は手動確認する
  → 1つでも当てはまったら: その業務は無理にWorkspace Studioに寄せず、既存の運用かZapier等の専門ツールを検討する

■ ステップ3：上限を業務規模と照らし合わせる
□ 作りたいフローの総数は25個以内に収まりそうか
□ 1フローに詰め込む処理は20ステップ以内で収まりそうか
□ Gmailをトリガーにするフローは25個以内か
  → いずれかNOなら、業務を複数フローに分割する設計を先に考える

■ ステップ4：機能変更のリスクを踏まえて本番投入の範囲を決める
□ 2025年12月の正式リリース時、Webhook送信・Chatスペース投稿ステップが予告なく削除された実例があることを理解しているか
  → YES: 外部連携が生命線の重要業務は、いきなり全面移行せず小さく試してから広げる
□ 2026年9月1日から実行回数の本上限適用が始まることを把握しているか
  → YES: それまでに使い方を固め、上限内で回る設計にしておく

■ ステップ5：それでも導入するかの最終判断
□ Workspace内（Gmail・Drive・Chat・Calendar・Sheets）で完結する定型作業か
  → YES: 導入価値が高い。テンプレートから小さく始める
□ 外部システム連携・複雑な条件分岐・大量データのループ処理が主役の業務か
  → YES: Workspace Studio単体では力不足。専門の自動化ツールと併用を検討する
```

**ポイント**: 「できないこと」に当てはまる業務は無理にWorkspace Studioへ寄せず、既存の運用や他ツールとの併用を検討してください。
