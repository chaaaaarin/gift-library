# 🎁 接続設定コピペ集(38点)

Claude CodeにMiniMax M3・Qwen3.8-Maxを接続するための設定スニペットと、接続後にタスクを振り分けるための指示文をまとめました。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 設定スニペットは `~/.claude/settings.json`(または`.claude/settings.local.json`)に貼り付け、APIキー部分を書き換えて保存するだけです。指示文はClaude Codeにそのまま貼って使えます。

## MiniMax M3 接続設定


### 1. MiniMax M3 基本の接続設定(国際版)

保存先: ~/.claude/settings.json

```text
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.minimax.io/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "<MiniMaxで発行したAPIキー>",
    "ANTHROPIC_MODEL": "MiniMax-M3"
  }
}
```


### 2. MiniMax M3 コンテキスト窓を実値に合わせる設定

保存先: ~/.claude/settings.json(基本設定に追記)。M3本来の100万トークンに合わせて早期の要約(オートコンパクト)を防ぐ

```text
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.minimax.io/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "<MiniMaxで発行したAPIキー>",
    "ANTHROPIC_MODEL": "MiniMax-M3",
    "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "1000000"
  }
}
```


### 3. MiniMax M3 プロジェクト単位の個別設定

保存先: <プロジェクト>/.claude/settings.local.json(このプロジェクトだけM3を使い、他は素のClaude Codeのままにしたいとき)

```text
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.minimax.io/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "<MiniMaxで発行したAPIキー>",
    "ANTHROPIC_MODEL": "MiniMax-M3"
  }
}
```


### 4. MiniMax M3 Extended thinkingをオフにする設定

保存先: ~/.claude/settings.json。単純作業でthinkingコストを省きたいときに

```text
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.minimax.io/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "<MiniMaxで発行したAPIキー>",
    "ANTHROPIC_MODEL": "MiniMax-M3",
    "MAX_THINKING_TOKENS": "0"
  }
}
```


### 5. MiniMax/Qwen接続後にOpusへ即座に戻す設定

保存先: ~/.claude/settings.json。envブロックを丸ごと削除するか、下記のように空にして保存すれば通常のClaude Opusに戻る

```text
{
  "env": {}
}
# 上記で保存すれば、次回起動時から通常のAnthropic公式(Claude Opus)に戻ります
```

# 🎁 コスト削減シミュレーションシート

現在のAI利用コストから、MiniMax M3・Qwen3.8-Maxへの切替でどれくらい削減できるかを概算するための早見表です。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 数字を埋めながら、そのままClaude Codeに計算を依頼してもOKです。

```text
【コスト削減シミュレーションシート】

■ ステップ1: 現在の月間トークン利用量を把握する
□ 月間の入力トークン数(百万トークン単位) = (　　　)
□ 月間の出力トークン数(百万トークン単位) = (　　　)
→ YES: 不明な場合は「直近1ヶ月のAPI利用量を集計して」とClaude Codeに依頼する

■ ステップ2: 現在(Claude Opus 5)のコストを計算する
公式: 入力(百万トークン)×$5 ＋ 出力(百万トークン)×$25 = 月間コスト(ドル)
→ YES: 計算した金額を控えておく

■ ステップ3: 切替候補モデルの単価を確認する
Qwen3.8-Max: 入力$2.00／出力$6.00(100万トークンあたり)
MiniMax M3: 入力$0.30／出力$1.20(100万トークンあたり)
→ YES: 同じ利用量で、それぞれの月間コストを計算する

■ ステップ4: タスク別の振り分け比率を仮決めする
□ 単純作業(振り分け候補)が全体の何割か = (　　　)%
□ 複雑な改修(Opusに残す分)が全体の何割か = (　　　)%
→ YES: 振り分け比率をかけ合わせて、混在後の概算コストを出す
指示例: 「月間利用量○百万トークン、単純作業が全体の◯割という前提で、MiniMax M3に振り分けた場合の月間コストをOpus単体の場合と比較して」

■ ステップ5: 削減額と削減率を出す
公式: 削減額 = 現在のコスト − 切替後の概算コスト
公式: 削減率(%) = 削減額 ÷ 現在のコスト × 100
→ YES: 削減額が検証コストに見合うか、「導入前チェックシート」と合わせて最終判断する

**ポイント**: 数字はあくまで概算です。実際のコストはタスクの複雑さ・失敗時の再実行回数などで変動するため、小規模な試験導入で実測してから本格運用に移すことをおすすめします。

指示例: 「直近1週間でClaude Codeに依頼したタスクを、単純作業/複雑な改修に分類して」

■ ステップ2: 価格差が見合うか計算する
□ 月間のトークン利用量を把握しているか(不明ならステップ2は一旦保留)
→ YES: 「コスト削減シミュレーションシート」で概算削減額を出す
□ 削減額が導入・検証の手間に見合う規模か
→ YES: ステップ3へ進む

■ ステップ3: ライセンス・利用規約を確認する
□ 商用利用が許可されたライセンスか、各社の公式ドキュメントで確認したか
→ YES: ステップ4へ進む
→ NO: 導入を保留し、確認が取れるまで待つ
指示例: 「MiniMax M3とQwen3.8-Maxの商用利用条件を、公式ドキュメントのURLつきで整理して」

■ ステップ4: 背景にある紛争を理解した上で判断する
□ Anthropicとの蒸留攻撃疑惑が係争中であることを理解しているか
→ YES: 自己責任の範囲で導入を判断する
□ 会社としての利用可否を確認する必要があるか(セキュリティ・法務部門があるチーム等)
→ YES: 導入前に社内確認を取る

■ ステップ5: 実運用の癖を先に把握しておく
□ MiniMax M3使用時のコンテキスト表示バグ(200K表示問題)を知っているか
→ YES: CLAUDE_CODE_AUTO_COMPACT_WINDOW設定を先に適用しておく
□ うまくいかなかったときにOpusへ戻す設定を用意しているか
→ YES: 「接続設定コピペ集」の切り戻し設定を手元に用意してから導入する
```

**ポイント**: 全ステップがYESになってから本番導入する必要はありません。まずは低リスクなタスクから小さく試すのが安全です。
