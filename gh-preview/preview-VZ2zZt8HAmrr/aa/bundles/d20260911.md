# 🎁 追加課金ゼロでCodexが動き出す 正規セットアップ手引き

受け取った日に、APIキーもクレジットカードも使わずにCodexが動く状態になります。さらに「枠に当たりにくい」モデル・思考量の設定と、枠が長持ちするタスクの出し方まで分かるので、裏技に手を出さなくても正規ルートで戦えるようになります。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 上から順に読み、「具体的な指示」の文はそのままCodexやChatGPTに貼って使えます。自分の環境（OS・使うクライアント）に合わせて読み替えてください。

```text
【追加課金ゼロでCodexを始める 正規セットアップ手引き】

──────────────────────────────
1. 正規ルートでサインインする（Sign in with ChatGPT）
──────────────────────────────
期待できるメリット: APIキー・クレジットカードなしでCodexが使える状態になる。
  API従量課金だと本格利用で月数十ドル以上かかることもあるが、この方法なら
  今のChatGPT月額（Free/Go/Plus/Pro）にすべて含まれるので追加ゼロ。
使う場面: これからCodexを触り始めるとき。または今までAPIキーで使っていて
  「思ったより課金が重い」と感じたとき。
前提: ChatGPTのアカウントを持っている（Freeでも可）。Node.js が入っている、
  または公式のデスクトップアプリを使える環境。
具体的な指示（Codex CLI を使う場合。ChatGPTに貼って手順をもらう）:
  「Codex CLI を、APIキーではなく "Sign in with ChatGPT" でセットアップしたいです。
   私のOSは（macOS / Windows / Linux のどれか）です。インストールから
   サインイン完了までの手順を、コマンドを1行ずつ、つまずきやすい点つきで教えてください。」
  IDE拡張（VS Code など）を使う場合は上の「Codex CLI」を「Codex の IDE 拡張」に、
  デスクトップアプリを使う場合は「ChatGPT デスクトップアプリの Codex モード」に置き換える。
出力形式: コマンドは1行ずつ、コピペで実行できる形。各コマンドの前に「何をするか」を1行。
  最後に「サインインできたか確認する方法」を1つ。
つまずきどころ: ブラウザが開いて認証を求められる → 同じPCの既定ブラウザでChatGPTに
  ログイン済みだとスムーズ。会社が管理するPCだと組織のポリシーでブロックされることがある
  （その場合は個人PCで試す）。

──────────────────────────────
2. 「枠に当たりにくい」モデルと思考量に設定する
──────────────────────────────
期待できるメリット: 同じ作業量でも枠（5時間ごと・週ごと）の消費が大きく減る。
  重いモデルと最大思考量を常用している人は、体感で数倍長く使えるようになることがある。
使う場面: 「すぐ枠切れする」「Plusだと足りない気がする」と感じているとき。
  最初の設定を見直すだけなので、作業前に1回やればよい。
前提: 手順1でサインイン済み。Codexのモデル選択と thinking / reasoning effort（思考量）の
  設定場所が分かる（分からなければ下の指示で聞く）。
具体的な指示（Codexに貼る）:
  「今の私のCodexの既定モデルと思考量の設定を教えてください。そのうえで、
   枠（rate limit）の消費を抑えることを優先した『普段用』の設定と、
   ここぞという難所だけ使う『本気用』の設定を、それぞれモデル名と思考量で提案してください。
   切り替え方（コマンドまたは設定画面の場所）も教えてください。」
出力形式: 「普段用 / 本気用」の2セットを、モデル名・思考量・切り替え方法の3点で。表でよい。
つまずきどころ: モデルを軽くしすぎると難しいタスクで失敗が増え、やり直しでかえって枠を食う。
  「普段はTerraかLuna、複雑な設計だけSol」のように使い分ける。思考量は1段ずつ下げて様子を見る。

──────────────────────────────
3. 重いタスクを「枠が長持ちする形」に分割する
──────────────────────────────
期待できるメリット: 1回の長い自律作業（複数ファイルをまたぐ実装など）は枠を一気に消費する。
  同じ内容でも小さく分けて出すと、途中で確認・軌道修正でき、失敗による無駄打ちが減る。
  結果として枠の減りがゆるやかになる。
使う場面: 「機能をまるごと作って」のような大きめの依頼を出す前。
  既に大きな依頼で枠切れした経験があるとき。
前提: 作りたいものの全体像を、自分の言葉で3〜6ステップに書けること（書けないうちは
  設計から相談する）。
具体的な指示（Codexに貼る）:
  「これから『（作りたいものを1〜2行で）』を実装します。いきなり全部作らず、
   レビューしやすい単位に分けた作業計画を、3〜6ステップで出してください。
   各ステップは『変更するファイル / やること / 完了の確認方法』の3点で。
   私がGOと言ったステップだけ着手してください。」
出力形式: 番号つきステップ。各ステップ3点セット。着手は1ステップずつ、こちらの合図制。
つまずきどころ: ステップが細かすぎると往復が増えて逆効果。1ステップ＝10〜20分で確認できる
  くらいの粒度が目安。計画に納得できないまま「全部やって」に戻さない。

──────────────────────────────
4. 枠の残りを確認する / 枠切れしたときの動き方
──────────────────────────────
期待できるメリット: 「あとどれくらい使えるか」を先に把握できると、締め切り前の作業を
  枠切れで止められずに済む。枠切れ時の選択肢を知っておくと慌てない。
使う場面: 大きめの作業に入る前。作業中に動作が急に重く・制限されたと感じたとき。
前提: 手順1でサインイン済み。
具体的な指示（Codexに貼る、またはCLIで実行）:
  「今のプランでのCodexの利用枠の残りと、リセットまでの時間を確認する方法を教えてください。
   （Codex CLIなら /status のような確認コマンド、デスクトップなら設定画面の場所）。
   枠を使い切ったときに取れる選択肢（待つ / クレジット追加 / プラン変更）も、
   今の私のプランで実際にできるものだけ教えてください。」
出力形式: 「確認する方法」1つ＋「枠切れ時の選択肢」を今のプランで可能なものだけ箇条書き。
つまずきどころ: OpenAIサポートは枠をリセットしてくれない。枠は5時間ごと・週ごとに自動で戻るので、
  急ぎでなければリセット時刻を待つのがいちばん安い。

──────────────────────────────
5. 「裏技」に手を出す前のセルフチェック
──────────────────────────────
期待できるメリット: あとで「規約違反だった」「アカウントが止まった」と後悔する事故を防ぐ。
  正規ルートで足りるなら、そもそも裏技のリスクを負う必要がない。
使う場面: 「ChatGPT WebをCodexに繋ぐ」系のツールを入れようか迷ったとき。
前提: 手順1〜4を試したうえで、それでも枠が足りないと感じている。
具体的な指示（自分への確認。別冊の「規約リスク判定シート」も併用）:
  ・OpenAIの利用規約「禁止事項」を自分で開いて読んだか
   （「アウトプットを自動又はプログラムにより引き出すこと」「レート制限や規制を回避」の2行）
  ・使うのは個人アカウント・個人PCか（会社アカウント／共用PCなら使わない）
  ・Codexに渡すコードに社外秘・顧客情報・認証情報が含まれないか
  ・止まっても困らない趣味の範囲か
出力形式: 上の4つすべてに自信を持って「はい」と言えなければ、裏技は使わず正規ルート＋Proにする。
つまずきどころ: 「みんな使っているから大丈夫」は判断材料にならない。「合法・安全」と
  言っているのが誰か（OpenAI公式か、有料教材を売る個人か）を必ず確認する。
```

**ポイント**: この手引きは「正規ルートで戦い切る」ための道具です。手順1〜4を試しても枠が足りず、かつ仕事で使うなら、規約リスクゼロの Pro が次の一手です。裏技は最後の選択肢、しかも趣味の範囲に限ってください。


### 3. 「無料でCodex」を使う前に、5分で"どこまでが安全か"を見極める判定シート（判断シート）
# このシートを上から順に埋めると、「ChatGPT WebをCodexに繋ぐ裏技」を自分が使ってよいか、業務で使えるか、代わりに何をすべきかが、迷わず決まります。感覚で「たぶん大丈夫」と手を出して、あとでアカウント停止やデータ流出で困る事故を防ぎます。

# 🎁 「無料でCodex」を使う前に、5分で"どこまでが安全か"を見極める判定シート

このシートを上から順に埋めると、「ChatGPT WebをCodexに繋ぐ裏技」を自分が使ってよいか、業務で使えるか、代わりに何をすべきかが、迷わず決まります。感覚で「たぶん大丈夫」と手を出して、あとでアカウント停止やデータ流出で困る事故を防ぎます。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: メモ帳などに貼り付け、□ の質問に YES / NO で答えながら上から進めます。1つでも「STOP」に当たったら、その先には進まず「代わりにやること」へ移ってください。

```text
【「無料でCodex」裏技 使う/使わない 判定シート】

■ ステップ1：そもそも正規ルートで足りているか（ここで多くの人は終わります）
□ 「Sign in with ChatGPT」でCodexにログインして使ったことがある？
  → NO: まずこれを試す。追加課金ゼロで動く。裏技の検討はそのあと
  指示例: 「Codex CLIで ChatGPTアカウントでサインインする手順を、私のOS向けに教えて」
□ 直近1週間で、実際に5時間・週の利用枠に当たって作業が止まったことがある？
  → NO: 裏技は不要。正規ルートのまま、モデルをLuna寄り・思考量を下げて様子を見る
  → YES: ステップ2へ
□ Pro（月100ドル〜）にすれば枠がゆるくなるのは知っている？予算を出せる？
  → YES: まずProを検討。規約リスクゼロで枠が広がる。裏技より先にこちら
  → NO: ステップ2へ

■ ステップ2：規約リスクを自分で確認する
□ OpenAIの利用規約「禁止事項」を自分で開いて読んだ？
  → NO: 先に読む（openai.com の利用規約 / 禁止事項）。「アウトプットを自動又はプログラムにより引き出すこと」「レート制限や規制を回避」の2行を必ず確認
□ この裏技が上の2行に触れる可能性がある、と理解したうえで進めようとしている？
  → NO（理解していない／触れないと思う）: STOP。理解できるまで使わない
  → YES: ステップ3へ
□ 「合法だから安全」と言っている情報の発信元は、OpenAI公式？それとも個人・有料教材の宣伝？
  → 個人・宣伝: その主張は根拠にしない。判断材料はOpenAIの規約側で取る

■ ステップ3：業務で使えるかの線引き（ここは厳しめに）
□ 使う予定のアカウントは「会社・チームのアカウント」？
  → YES: STOP。会社アカウントでのブラウザ自動操作・上限回避は、職場の規約や情報管理ルールに触れる可能性が高い。正規ルート＋Proにする
□ Codexに渡す予定のコードやファイルに、社外秘・顧客情報・認証情報が含まれる？
  → YES: STOP。非公式ツール経由で外部サービスに流すのは避ける
□ 使うPCは、自分専用の個人PC？（共用PC・貸与PCではない）
  → NO: STOP。ログイン情報を持つブラウザ設定が他人から触れる状態にしない

■ ステップ4：それでも個人の趣味で試すなら（自己責任の前提）
□ インストールコマンドの中身（何をダウンロードして実行するか）を自分で確認した？
  → NO: 確認してから。中身を読まずにコマンドを実行しない
□ 「フルモード」を使う場合、手元PCのファイル・コマンドまで到達する権限を渡すと理解している？
  → NO: フルモードは使わない。ブラウザのみのモードにとどめる
□ chatgpt.comの画面が変わると突然動かなくなる、と理解して依存しすぎない運用にしている？
  → NO: 本番の締め切り作業をこのツールに乗せない
□ アカウントが停止されても困らない範囲（趣味・練習用）で使う？
  → NO: STOP。止まると困る用途では使わない

■ 判定
・ステップ1で終わった → 正規ルート（＋必要ならPro）で十分。裏技は不要
・ステップ3でSTOP → 業務・機密・共用PCでは使わない。正規ルート一択
・ステップ4まで全部YES → 個人の趣味の範囲でなら、規約グレーと理解したうえで自己責任で

■ 代わりにやること（裏技を使わない選択をした人向け）
1. 「Sign in with ChatGPT」で正規のCodexを使う（追加課金ゼロ）
2. モデルをLuna寄りにし、思考量を1段下げて枠を節約する
3. 枠が足りず仕事で使うなら Pro にする
指示例: 「Codexで枠の消費を抑えたい。モデルと思考量（reasoning effort）のおすすめ設定と、重いタスクを分割するコツを教えて」
```

**ポイント**: このシートの「STOP」は、法律の断定ではなく「規約に触れる疑いが濃く、止まると損が大きい」という意味です。最終判断は必ず自分でOpenAIの規約を読んで行ってください。
