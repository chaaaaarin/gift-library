# 🎁 頭の中3ノートテンプレート（自己紹介／判断基準／進行中）

AIエージェントに「自分が何者か」を一生忘れさせないための3つのメモです。Obsidianのボルト直下にこの3つをMDファイルとして保存しておくと、新しいセッションを開くたびに前提を説明し直す必要がなくなります。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 各ノートの「書式」部分だけをコピーしてObsidianの新規ノートに貼り、空欄を自分の内容に書き換えてください。「記入例」はそのまま消して構いません。

### 1. 自己紹介ノート（profile.md）

説明: AIに「あなたが何者か」を教える一番土台のメモです。ここが充実しているほど、AIはあなた向けの回答を返してくれるようになります。

```text
書式:
自己紹介

◆仕事・役割
- 職種／立場：
- 担当している業務：

◆今のチーム・環境
- 使っているツール：
- 一緒に働く相手：

◆よく使うAIツール
- 普段使うAIエージェント：
- 得意な使い分け（例：長文作成はA、コード修正はB）：

◆好み・スタイル
- 文章のトーン（例：敬体／簡潔／絵文字なし）：
- 出力形式の好み（例：箇条書き優先）：

記入例:
自己紹介

◆仕事・役割
- 職種／立場：YouTubeチャンネル運営・動画制作ディレクター
- 担当している業務：企画立案、台本作成、分析レポート作成

◆今のチーム・環境

- 一緒に働く相手：編集者1名、AIエージェント複数

◆よく使うAIツール

```

### 2. 判断基準ノート（判断基準.md）

説明: 「これはやる／やらない」をAIが自分で判断できるようにする基準集です。毎回口頭で説明していたルールをここに書き溜めると、AIが提案の時点で基準に沿ってくれるようになります。

```text
書式:
判断基準

◆大事にしていること
- 

◆やらないと決めていること
- 

◆迷ったときの優先順位
1. 
2. 
3. 

記入例:
判断基準

◆大事にしていること
- 視聴者が最後まで見られる分かりやすさを最優先する
- 数字や一次情報は必ず出典を確認してから使う

◆やらないと決めていること
- 誇張したタイトル・クリックベイトだけの煽り文句は使わない
- 未確認の情報を断定形で書かない

◆迷ったときの優先順位
1. 正確性（間違った情報を出さない）
2. 分かりやすさ（初心者が置いていかれない）
3. 効率（時間をかけすぎない）
```

### 3. 進行中ノート（進行中.md）

説明: 「今どのプロジェクトの何が動いているか」をAIと共有し続けるための更新型メモです。デイリーノートと違い、終わったタスクは消して常に“今”だけを映す使い方をします。

```text
書式:
進行中

◆今動いているプロジェクト
- プロジェクト名：
  - 現状：
  - 次にやること：
  - 期限：

◆保留中・様子見
- 

記入例:
進行中

◆今動いているプロジェクト
- プロジェクト名：No.127 Obsidian解説動画
  - 現状：台本ドラフト完成、プレゼント制作中
  - 次にやること：サムネ確定、公開日調整
  - 期限：2026-09-14

◆保留中・様子見
- 新シリーズ企画（他チャンネルの反応を見てから判断）
```

**ポイント**: 3つとも「完璧に埋める」必要はありません。まずは分かる範囲だけ書いて保存し、使いながら育てていくのがコツです。散らかった書き方はAIが読み取って整理してくれます。

# 🎁 永続メモリ活用 指示文3本＋出力見本

Obsidianに溜めた記憶をAIエージェントにちゃんと使わせるための指示文3本です。「聞き出す」「忘れさせない」「整える」の3段階で、それぞれ実際にどんな返答が返ってくるかの出力見本も付けています。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 場面に合った指示文の〔　〕部分を自分の内容に書き換えて、いつものAIエージェントに貼るだけです。

### 1. 過去の記録を掘り起こして答えさせる

説明: Obsidianに保存済みのメモ・データを前提に、AIに聞くだけで答えを引っ張ってきてもらう指示文です。日付や固有名詞を含めるほど、AIがボルト内を正確に探しに行きます。

```text
指示文:
〔チャンネル名／プロジェクト名〕の〔日付〕の〔対象〕について、Obsidianのボルト内にあるメモやデータから分かることを教えて。無ければ「ボルト内に情報がない」と正直に言って。

出力見本:
ボルト内を確認しました。「AIエージェントチャンネル/2026-05-25」フォルダに該当のアナリティクスCSVと個別レジェンドメモがあったので、そちらから集計します。

- 視聴回数：9,610回
- インプレッション：96,234回
- クリック率：約10.0%
- メモにある補足：「サムネのA/Bテストで文字色を変えた回」

この3点はメモとCSVの両方に記録があるため確度が高いです。それ以外のコメント傾向などはボルト内に情報がなかったので回答できません。
```

### 2. 修正内容を「二度と忘れない反省情報」として記録させる

説明: 指摘した直しをその場限りで終わらせず、次から自動で守らせるための指示文です。この一文をルールとして冒頭に置いておくと、「反省情報を書いて」と言わなくてもAIが会話の最後に自分から残してくれるようになります。

```text
指示文（ルールとして常時有効にしておく）:
今後、私から修正・やり直しの指示が入ったら、そのやり取りの最後に必ず「反省情報」を1件、短く具体的にreflections.mdへ追記して。書式は「発生日／何が起きたか／なぜ起きたか／次から守ること」の4行。私から「反省情報を書いて」と言われなくても、修正が入った会話では毎回自動で行って。

出力見本:
（修正指示への対応が終わった後、AIが自動で追記）
reflections.md に追記しました。

◆見出しの文字数オーバー
- 発生日：2026-09-11
- 何が起きたか：スライド見出しが1行に収まらず折り返した
- なぜ起きたか：全角20文字の上限を確認せずに書いた
- 次から守ること：見出しを書く前に全角20文字以内かを必ず数える
```

### 3. 溜まった情報を週1で棚卸しさせる

説明: 足すだけだと情報はどんどん古くなって溜まっていきます。週に1回、AIに整理を任せる指示文です。オートメーション（定期実行）に登録しておけば、意識しなくてもボルトがきれいな状態を保てます。

```text
指示文（週1回、定型で投げる／自動化にも登録可能）:
reflections.md と 進行中.md を確認して、①もう当てはまらなくなった反省情報、②2週間以上更新のない「進行中」の項目、を見つけて。削除していいか判断できるように、それぞれ理由付きでリストにして。実際の削除は私が確認してから行って。

出力見本:
棚卸し結果です。

【もう当てはまらない反省情報（削除候補）】
- 「動画IDの取り違え」ルール（2026-08-10追加）→ 該当する作業フロー自体が9月から自動化され、発生しうる状況が無くなったため

【2週間以上動きのない「進行中」項目】
- 「新シリーズ企画」→ 最終更新2026-08-20のまま。保留中に移すか、着手するか判断をお願いします

上記2件について、削除／保留への移動のご指示をください。
```

**ポイント**: 3本とも「聞きっぱなし」にしないのがコツです。1と2はやり取りの中で自然に発生させ、3だけは自分から定期的に投げる。この3段階が回り出すと、使うほどAIが賢くなっていく状態に入ります。
