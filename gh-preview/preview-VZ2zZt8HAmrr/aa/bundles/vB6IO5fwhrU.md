# 🎁 Codex神プラグイン30選 導入プロンプト90選

30個のプラグインを、1個につき3本ずつ「そのまま貼って試せる」プロンプトにしました。プラグインをインストールした後、対応するプロンプトを貼るだけで使い始められます。

**受け取り方**: 各カードのボタンでコピー、または全件ダウンロードしてください。GitHub上ではこのファイルのコードブロックから直接コピーできます。

**使い方**: 該当するプラグインをインストールしてから、対応する番号のプロンプトをCodexのチャット欄に貼り付けてください。

## 公式定番
### 1. GitHub — 例1
```text
このリポジトリの未マージのPRを一覧にして、レビュー待ちが長い順に並べて教えて。それぞれ、誰がレビュー待ちで止まっているか、放置されている日数も添えて。
```
### 2. GitHub — 例2
```text
このPRの差分を確認して、バグの可能性や設計上の懸念があれば指摘して。良い変更であればそれも伝えつつ、そのままレビューコメントとして投稿できる文面案を作って。
```
### 3. GitHub — 例3
```text

```
### 4. Slack — 例1
```text
このチャンネルの今日のやり取りを要約して。決定事項と、まだ誰も対応していないタスクを分けてリストにし、タスクには関係してそうな担当者も添えて。
```
### 5. Slack — 例2
```text

```
### 6. Slack — 例3


# 🎁 Codexプラグイン選定フローチャート

「結局どれを入れればいいのか」を5ステップで判断できるチェックリストです。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 上から順に読み、該当する項目のYESの先を実行してください。

```text
【Codexプラグイン選定フローチャート】

■ ステップ1：まず入れるべきか判断する
□ 同じ作業を今後も繰り返す予定がある
→ YES: プラグイン化を検討する
□ 1回きりの作業である
→ YES: プラグインを入れずにその場で頼む

■ ステップ2：カテゴリを選ぶ
□ Slack・Notion・Gmail等、普段使っているツールと連携したい
→ YES: 公式定番8選から選ぶ
□ 自分の職種（データ分析・営業・デザイン等）に近い作業をしたい
→ YES: 職種特化6選から選ぶ
□ サイトやアプリを作って公開したい
→ YES: 制作・自動化6選から選ぶ
□ 開発の質そのものを底上げしたい
→ YES: コミュニティ精鋭6選から選ぶ
□ 今すぐ試せる最新の面白いものを知りたい
→ YES: 最新トレンド速報4選から選ぶ
指示例: 〇〇をやりたいが、どのプラグインが合うか提案して、そのまま進めて。

■ ステップ3：信頼できるか確認する
□ 公式提供、またはGitHub star数万以上等の実績がある
→ YES: そのまま導入してよい
□ 実績が確認できない、聞いたことがない
→ YES: 導入前に評判・実績を確認する
指示例: このプラグインの提供元と実績を確認してから、導入するかどうか判断して。

■ ステップ4：権限を確認する
□ 読み取りだけで十分な用途である
→ YES: 権限は読み取りのみに絞る
□ 書き込み・送信・削除等の操作が必要
→ YES: どの操作が必要か具体的に確認してから許可する
指示例: このプラグインに与える権限を確認して、今回の用途に対して権限が広すぎないか教えて。

■ ステップ5：入れすぎていないか定期的に見直す
□ 使っていないプラグインが増えてきた
→ YES: 棚卸しして不要なものを外す
指示例: 今接続しているプラグインを一覧にして、それぞれ最後に使ったのがいつか分かる範囲で教えて。使っていないものがあれば教えて。
```
