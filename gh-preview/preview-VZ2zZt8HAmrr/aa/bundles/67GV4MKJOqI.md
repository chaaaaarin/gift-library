# 🎁 外出前5分セットアップ・チェックリスト

外出先からスマホでCodexに仕事をさせるために、家を出る前にPC側で確認しておくことを、上から順に潰せるチェックリストにしました。ここが抜けると、外出先で開いた時に何も動いていなかった、という事故が起きます。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 家を出る5分前に開いて、ステップ1から順に□を潰してください。読む順番がそのまま作業の順番です。

```text
【外出前5分セットアップ・チェックリスト】

■ ステップ1：PCが途中で止まらない状態にする
□ PCが電源アダプタに挿さっているか
→ YES: 次へ進む
→ NO: 今すぐ挿す（外出先からバッテリー切れは絶対に復旧できない）
□ 画面を閉じてもスリープしない設定になっているか
→ YES: 次へ進む
→ NO: スリープするとCodexの処理も一緒に止まる。Macなら省エネルギーの設定を変えるか、スリープを防ぐ常駐ツールを入れておく。Windowsなら電源プランをスリープなしに変える
□ 外出中に自動アップデートや自動再起動が走らない設定になっているか
→ YES: 次へ進む
→ NO: 外出中だけ一時的に止める（再起動されるとCodexアプリも一緒に落ちる）
□ 有線か安定したWi-Fiに繋がっているか
→ YES: 次へ進む
→ NO: 安定した回線に繋ぎ直す

■ ステップ2：Codexを待機状態にしておく
□ PC側でCodexアプリを起動したままにしているか
→ YES: 次へ進む
→ NO: 起動する（アプリが閉じているとスマホから呼び出せない）
□ 今日やらせたいプロジェクトのフォルダを開いた状態か
→ YES: 次へ進む
→ NO: 開いておく（作業場所が決まっていないと、外出先で指示しても迷子になる）
□ 前の作業が途中で止まったまま残っていないか確認したか
→ YES: 次へ進む
→ NO: 完了させるか、いったん終わらせてから出る（止まったまま残っていると新しい指示が後回しになる）
指示例: 今開いているフォルダの中身を一覧にして、今日の作業対象がそろっているか確認してください。

■ ステップ3：スマホとPCのペアリングを確認する
（ペアリングとは、スマホのChatGPTアプリとPCのCodexを繋いでおく紐づけのこと。QRコードを読み取って繋ぐ）
□ スマホのChatGPTアプリから、自宅や職場のPCが一覧に出てくるか
→ YES: 次へ進む
→ NO: PC側のCodexでQRコードを表示し、スマホで読み取って繋ぎ直す（家を出たあとでは繋ぎ直せない）
□ 実際にスマホから短い指示を1つ送って、PC側が反応したか
→ YES: 次へ進む
→ NO: PCの回線とCodexアプリの起動状態を確認して、もう一度試す
指示例: 接続確認です。今日の日付と、いま開いている作業フォルダの名前を教えてください。

■ ステップ4：必要なプラグインを繋いでおく
（プラグインとは、Codexを外部のサービスに繋ぐ差し込み口のこと。繋ぐべきは、仕事の連絡が来る場所と、素材が置いてある場所の2つ）
□ 依頼や連絡が届く場所（チャットツールやメール）と繋がっているか
→ YES: 次へ進む
→ NO: 出発前に繋いでおく（外出先でログインや認証をやり直すのは時間がかかる）
□ 素材や資料を置いているクラウドストレージと繋がっているか
→ YES: 次へ進む
→ NO: 繋いでおく
□ 繋いだプラグインで、実際に中身が読めるか一度試したか
→ YES: 次へ進む
→ NO: 読み取りを1回だけ試して確かめる（繋がっているだけで読めないことがある）
指示例: いま繋がっているプラグインを一覧にして、それぞれ中身を読み取れる状態か確認して報告してください。

■ ステップ5：Computer Useを使うかどうか決める
（Computer Useとは、Codexがマウスとキーボードを操作して、PCの画面を直接動かす機能のこと）
□ 今日やらせたい作業に、ソフトを操作する工程が含まれるか
→ YES: 出発前に有効にしておく（外出先からは有効化しにくい）
→ NO: オフのままでよい（使わないなら切っておく方が安全）
□ 有効にする場合、操作させたいソフトを起動して画面に出してあるか
→ YES: 次へ進む
→ NO: 起動して、最初の画面まで開いておく
□ 画面に見られたくないもの（個人情報、他社の資料など）が映っていないか
→ YES: 次へ進む
→ NO: 閉じてから出る

■ ステップ6：承認モードを決める
（都度承認とは、作業のたびにこちらの許可を待って止まる設定。フルアクセスとは、いちいち聞かずに最後まで進む設定）
□ 今日やらせるのは、失敗してもやり直せる作業か（調べもの、集計、下書き作成、素材の取り込みなど）
→ YES: フルアクセス寄りにして、外出先で止まらないようにする
→ NO: 都度承認のままにする
□ 消す、送る、公開する、支払う、のどれかが含まれるか
→ YES: 都度承認にする。またはその手前で必ず止まるよう先に指示しておく
→ NO: 次へ進む
□ フルアクセスにする場合、触らせるフォルダを今日の対象だけに絞れているか
→ YES: 次へ進む
→ NO: 対象を限定してから出る（権限を強くする時ほど、範囲を狭めるのが一番の安全策）
指示例: 今日の作業は下書きの保存までで止めてください。送信、公開、削除はしないでください。

■ ステップ7：モデルと処理速度を選ぶ
（賢さと速さは基本的に逆になる。一番賢いが遅いもの、中間、速くて安いもの、の3段階から選ぶ）
□ 今日の作業は、判断や組み立てが必要な重い作業か
→ YES: 一番賢いモデルを選ぶ（遅くても、外出中に走らせるなら待ち時間は問題にならない）
→ NO: 次の項目へ進む
□ 短い調べものや、決まった形の繰り返し作業が中心か
→ YES: 速くて安いモデルでよい
→ NO: 中間のモデルを選ぶ
□ 重い作業に一番軽いモデルを割り当てていないか、選び直す前に見返したか
→ YES: 次へ進む
→ NO: 選び直す（ここを間違えると、帰宅後に中途半端な結果だけが残る）

■ ステップ8：素材と出力先を整える
□ 今日使う素材が、PCから開ける場所に置いてあるか
→ YES: 次へ進む
→ NO: PC内のフォルダか、同期済みのクラウドフォルダに移す
□ ファイル名を見ただけで中身が分かるか
→ YES: 次へ進む
→ NO: 分かる名前に直す（外出先からは中身を目で確かめられない）
□ 出来上がったものを入れる出力先フォルダを決めてあるか
→ YES: 次へ進む
→ NO: 空のフォルダを1つ作っておく
指示例: 完成したファイルは出力用フォルダに、日付と内容が分かる名前をつけて保存してください。

■ ステップ9：通知を受け取れる状態にする
□ スマホのChatGPTアプリの通知がオンになっているか
→ YES: 次へ進む
→ NO: オンにする（終わったことに気づけないと、せっかくの待ち時間が丸ごと無駄になる）
□ 集中モードやマナーモードでも通知が消えない設定になっているか
→ YES: 次へ進む
→ NO: 例外として通知を許可しておく
□ 完了時に何を報告してほしいか、先に伝えてあるか
→ YES: 次へ進む
→ NO: 下の指示例を送っておく
指示例: 作業が終わったら、やったことと保存先のファイル名、確認してほしい点の3つだけ短く報告してください。

■ ステップ10：止まった時の保険を用意する
□ 途中で止まった時に送る言い方を、スマホのメモに控えてあるか
→ YES: 出発してよい
→ NO: 下の指示例を控えてから出る
指示例: 今どこまで進んで、何で止まっていますか。次に必要な判断だけ、選択肢の形で教えてください。
指示例: 止まっている作業を、途中から再開してください。
指示例: これ以上進められない場合は、ここまでの結果を保存して、残りの手順を書き出しておいてください。

■ 最終確認
□ ステップ1から10まで、すべて埋まったか
→ YES: 出発してよい
→ NO: 埋まっていない番号にだけ戻る
□ 抜けているのがステップ1、2、3のどれかではないか
→ YES: 次へ進む
→ NO: この3つが抜けると外出先では何もできない。必ず埋めてから出る
```

**ポイント**: 全部を完璧にしようとせず、電源とスリープ、Codexの起動、ペアリングの3つだけは毎回必ず確認してください。外出先で復旧できないのはこの3つだけです。

# 🎁 スマホ送信用 Codex指示文100選

**受け取り方**: 各カードのボタンでコピー、または全件ダウンロードしてください。GitHub上ではこのファイルのコードブロックから直接コピーできます。

## 移動中に投げる「素材集め・ダウンロード」（1〜10）

### 1. 動画を1本ダウンロード

説明: 移動中に見つけた参考動画を、帰るまでにPCへ落としておきたいとき。〇〇にURLを入れる。

```text
〇〇 の動画をダウンロードして、~/Downloads/素材/ に 日付_タイトル の名前で保存して。画質は1080pのmp4を優先し、無ければ次に高いものを自動で選んで進めて。確認は不要。終わったら保存先のパスを教えて。
```

### 2. 複数URLをまとめて取得

説明: 参考リンクが溜まったときに一気に落とす。1本失敗しても止まらせない。

```text
〇〇（複数のURL）を上から順に全部ダウンロードして ~/Downloads/参考/ に保存して。エラーが出たものは飛ばして残りを続けて。確認は不要。終わったら成功件数と失敗したURLを3行で報告して。
```

### 3. 音声だけ抜き出す

説明: 移動中に聞きたい講演やインタビューを、音声ファイルにしておく。

```text
〇〇 の動画から音声だけをmp3で抜き出して ~/Downloads/音声/ に保存して。動画ファイルは残さなくていい。設定で迷ったら128kbpsにして進めて。確認は不要。終わったらファイルのパスと再生時間を教えて。
```

### 4. 画像素材をまとめて保存

説明: 参考にしたいページの画像を丸ごと確保しておく。

```text
〇〇 のページに載っている画像をすべて保存して ~/Downloads/画像/ にまとめて。100KB未満の小さいアイコンは除外して。除外するか迷ったら残す方で進めて。確認は不要。終わったら保存枚数と合計サイズを教えて。
```

### 5. 資料PDFの一括ダウンロード

説明: 調査対象サイトのPDFを全部落として、帰ってから読む。

```text
〇〇 のページからPDFのリンクを全部見つけてダウンロードし、~/Downloads/資料PDF/ に保存して。同名があれば末尾に連番を付けて上書きしないで。確認は不要。終わったらファイル名の一覧を報告して。
```

### 6. クラウドから必要ファイルを落とす

説明: Googleドライブのプラグインを繋いである前提。ファイル名の一部を〇〇に入れる。

```text
Googleドライブのプラグインで「〇〇」を名前に含むファイルを探して、更新日が新しい3件をPCの ~/Downloads/ドライブ/ に保存して。候補が多ければ新しい順に3件へ絞って進めて。確認は不要。終わったらファイル名と更新日を報告して。
```

### 7. 散らかったフォルダの仕分け

説明: ダウンロードフォルダが崩壊しているとき、移動だけで整える。

```text
~/Downloads/ の中身を拡張子ごとのフォルダに仕分けして。移動だけで、削除や上書きはしないで。同名は連番を付けて避けて。分類に迷ったら「その他」に入れて進めて。確認は不要。終わったら仕分け結果を3行で報告して。
```

### 8. 容量を食っているファイル探し

説明: ディスクが埋まってきたとき、消す前に一覧だけ作らせる。

```text
~/Downloads/ と ~/Desktop/ から1GB以上のファイルを探して、大きい順の一覧をデスクトップにテキストで書き出して。削除は絶対にしないで一覧だけ作って。確認は不要。終わったら上位3件とファイルのパスを報告して。
```

### 9. カメラ素材の中身を確認

説明: カードから吸い出した素材が何本・何分あるか、外出先で把握する。

```text
~/Movies/カメラ素材/ の動画を全部調べて、ファイル名・再生時間・解像度・作成日の一覧をCSVでデスクトップに作って。読めないファイルは「不明」と書いて先に進めて。確認は不要。終わったらCSVのパスと本数を教えて。
```

### 10. 素材のバックアップ

説明: 上書き事故が怖い作業。まず計画を立てさせ、危険な場面だけ止める。

```text
~/Movies/カメラ素材/ を外付けドライブにコピーする手順を、まずプランモードで組み立てて。問題なければそのまま実行して。既存ファイルの上書きが発生する場合は実行前に必ず私に確認して。終わったらコピー件数を3行で報告して。
```

## メール・チャットの処理（11〜20）

### 11. 未読メールの仕分け

説明: 電車の中で「何が燃えているか」だけ先に把握する。

```text
メールのプラグインで今日届いた未読を全部読んで、至急・今日中・今週中・見るだけ の4つに分類して。迷ったら「今日中」に入れて進めて。返信は送らないで。確認は不要。終わったら分類ごとの件数と至急の件名を報告して。
```

### 12. 返信文の下書きだけ作る

説明: 帰ってから送信ボタンを押すだけの状態にしておく。送信はさせない。

```text
未読メールのうち返信が必要なものに、丁寧語の返信案を1通ずつ作ってデスクトップの 返信案.txt にまとめて。送信は絶対にしないで下書きだけにして。情報が足りない箇所は【要確認】と書いて進めて。終わったらパスと通数を教えて。
```

### 13. 期限つき依頼だけ抜き出す

説明: メールの山から「期限のあるもの」だけを拾わせる。

```text
過去24時間のメールから、期限や依頼が書かれているものだけを抜き出して、送信者・依頼内容・期限 の3列で一覧にして。曖昧なものは「期限不明」として載せて進めて。確認は不要。終わったら件数と一番早い期限を報告して。
```

### 14. チャットの見逃しを拾う

説明: Slackのプラグインを繋いである前提。読むだけで書き込ませない。

```text
Slackのプラグインで、自分宛のメンションとDMを過去1日ぶん確認して、対応が必要なものを箇条書きにして。返信や書き込みはしないで読むだけにして。迷ったら載せる方で進めて。確認は不要。終わったら件数と上位3件を報告して。
```

### 15. 長いスレッドを3行に

説明: 100件を超えたスレッドを、駅から歩きながら把握する。

```text
〇〇（スレッドのURLかタイトル）を最初から最後まで読んで、決まったこと・保留・自分がやること の3つに分けて3行にまとめて。書き込みはしないで。判断に迷ったら「保留」に入れて進めて。終わったらその3行だけ返して。
```

### 16. 自分の定型文を発掘する

説明: 過去の自分のメールから、使い回せる言い回しを資産化する。

```text
過去に自分が送ったメールから、よく使っている言い回しを10個抜き出して、デスクトップに 定型文.txt として保存して。個人名や社名は〇〇に置き換えて。迷ったら置き換える方で進めて。確認は不要。終わったらパスを教えて。
```

### 17. 名刺からお礼メールの下書き

説明: 展示会や交流会の帰り道に投げる。送信はさせない。

```text
~/Documents/名刺/ の画像から会社名と氏名を読み取って、初回のお礼メールの下書きを1人ずつ作ってテキストにまとめて。送信はしないで。読めない文字は【判読不可】として進めて。確認は不要。終わったら人数とパスを教えて。
```

### 18. 返事が来ていない相手を洗う

説明: 追いかけ漏れを防ぐ。催促文はやわらかい下書きまで。

```text
自分が送ったメールで1週間以上返事が来ていないものを探して、やわらかい催促文の下書きを1通ずつ作って。送信はしないで下書きだけにして。迷ったら候補に入れて進めて。確認は不要。終わったら相手先の一覧を3行で報告して。
```

### 19. 英文メールの翻訳と要点

説明: 海外取引先からのメールを日本語で把握する。

```text
受信箱の英文メールを全部日本語に訳して、要点と返信の要否を1件ずつ書き出して。訳が多少ぎこちなくても意味が通れば先に進めて。返信は送らないで。確認は不要。終わったら件数と返信が必要な件名を報告して。
```

### 20. 不在通知の文案を用意

説明: 明日から出張・休暇のとき。設定変更はさせず文案だけ。

```text
明日から2日間の不在に備えて、日本語と英語の不在返信の文案をデスクトップに作って。メールの設定は変更しないで文案だけにして。書き方に迷ったら丁寧な方を選んで進めて。確認は不要。終わったらファイルのパスを教えて。
```

## 会議のあと・議事録まわり（21〜30）

### 21. 録音から議事録を作る

説明: 会議室を出た直後、次の移動中に投げる定番の1通。

```text
~/Documents/会議録音/ の一番新しい音声を文字起こしして、決定事項・宿題・次回日程 の3見出しで議事録を作りデスクトップに保存して。聞き取れない箇所は【不明瞭】として先に進めて。確認は不要。終わったらパスと決定事項を3行で報告して。
```

### 22. 議事録からタスクを抜く

# 🎁 Record & Replayでスキルを量産する手順ガイド

自分がPCで一度やってみせた操作を録画すると、Codexがそれを再現できる手順（スキル）に変えてくれる機能の使い方をまとめたガイドです。プロンプトが書けなくても、やって見せるだけで定型業務を自動化できます。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 上から順に読み、まずは3分以内で終わる小さな作業をひとつ選んで録画してみてください。

```text
【Record & Replayでスキルを量産する手順ガイド】

■ Record & Replayとは何か
自分がPCで実際にやった操作を録画すると、Codexがその流れを読み取って、あとから同じことを再現できる手順書に変えてくれる機能です。この手順書のことをスキルと呼びます。
一度スキルにしてしまえば、次からはスキルの名前を伝えるだけで、同じ作業が最初から最後まで自動で走ります。

■ 何が嬉しいのか
□ 指示の文章を書けなくても自動化できる
やり方を言葉で説明するのは難しくても、やって見せるだけなら誰でもできます。説明が苦手な作業ほど向いています。

□ 頭の中にしかない手順が形に残る
自分だけがやり方を知っている作業を、他の人にも渡せる形にできます。引き継ぎ資料を書く手間が減ります。

□ 外出先から呼び出せるようになる
スキルにしておけば、スマホからスキル名を送るだけでPC側の作業が走ります。手順を毎回説明する必要がなくなります。

■ 起動のしかた
1. PCでCodexを開き、いつも指示を書いているチャット欄にカーソルを置きます。
2. 半角のスラッシュを1つ入力します。使えるコマンドの一覧が出てきます。
3. その中から Record & Replay を選びます。
4. 一覧に出てこない場合は、プラグインの設定画面を開き、Record & Replay を追加してからもう一度スラッシュを入力してください。
5. 録画開始を押したら、あとはいつもどおりに作業するだけです。終わったら停止を押します。

■ 録画する前の準備（ここで9割決まる）
□ 関係ないウィンドウをすべて閉じる
録画中に映ったものは、すべて手順の一部として拾われる可能性があります。今日の作業に必要な画面だけを開いてください。

□ 通知を切る
録画の途中でチャットやメールの通知が飛び出すと、その操作まで手順に混ざります。集中モードなどで通知を止めてから始めてください。

□ 個人情報や見せたくない画面を開かない
給与明細、他社の資料、パスワードの入っている画面などは、録画前に必ず閉じます。ブラウザのタブも確認してください。

□ 毎回変わる値を決めておく
日付、案件名、担当者名、金額など、実行のたびに変わるものがあります。録画前に「今日はこれを変数として扱う」と決めておき、その値をコピー＆ペーストで入力するようにすると、あとで直しやすくなります。

□ 作業の最初と最後をはっきり決める
どこから始めてどこで終わるかを、録画開始前に一言で言えるようにしておきます。言えないなら、その作業はまだ大きすぎます。

□ 練習で一度やってみる
本番の録画の前に、同じ作業を一度通しでやってみてください。迷う箇所が見つかったら、それは録画では詰まるところです。

■ 録画中のコツ
□ 迷わず一本道でやる
最短のルートを一度だけ通ります。あちこち開いて確かめる動きが入ると、その確認作業まで手順に含まれてしまいます。

□ 途中でやり直さない
間違えたら、その場で戻さず録画を止めて、最初から録り直してください。やり直しの操作まで手順として学習されてしまいます。

□ ゆっくり確実に操作する
速く動かす必要はありません。1つ操作したら画面が切り替わるのを待ってから、次に進みます。

□ 分岐がある作業は分けて録る
もしAならこうする、Bならこうする、という枝分かれは1本の録画に入れないでください。AのスキルとBのスキルに分けて、それぞれ録ります。

□ 迷いやすい場所では手を止めない
どのボタンを押すか考え込む時間が長いと、その部分の手順があいまいになります。考えるのは録画前に済ませておきます。

□ 5分を超えそうなら区切る
長い録画は再現の精度が落ちます。工程ごとに区切って、複数のスキルにしてください。

□ 生成されたスキルを最後まで読む

□ 名前を分かりやすくする
自分が3か月後に見ても分かる名前をつけます。何をするスキルなのかが名前だけで伝わることが基準です。スマホから呼ぶ時に打ちやすい短さも意識してください。

□ 説明文を1行つける
どんな時に使うスキルなのかを1行で書いておくと、数が増えた時に迷わなくなります。

□ 一度テスト実行する
録画時とは別のデータで実行して、同じ結果になるかを確かめます。ここで初めて実用になります。
指示例: 作ったスキルを、別のファイルを対象にしてテスト実行してください。途中で止まった箇所があれば教えてください。

□ 失敗した時の逃げ道を決める
うまくいかなかった場合にどこまで戻ればいいかを、スキルの説明に書き添えておきます。

■ うまくいかない時
□ 録画が長すぎて、途中から再現できない
→ 工程ごとに区切って、複数のスキルに分けて録り直してください。ひとつのスキルは5分以内が目安です。

□ 画面のレイアウトが変わって再現できない
→ Computer Use（Codexが画面を直接操作する機能）を有効にしてください。ボタンの位置ではなく画面を見て判断できるようになり、多少の変化に強くなります。

□ 毎回同じところで止まる
→ 止まる手順だけを切り出して、その部分だけを短く録り直してください。前後をつなぎ直す方が、全体を録り直すより確実です。

□ 実行するたびに違う結果になる
→ 固定すべき値が指定されていない可能性があります。出力の形式や保存先を、スキルの中に明記してください。

□ 意図しないファイルまで触ってしまう
→ 対象フォルダをスキルの中で限定してください。範囲を狭めるのが一番効きます。

□ 録画したのにスキルが生成されない
→ 操作が短すぎるか、画面上の変化がほとんどなかった可能性があります。もう少し工程を足して録り直してください。

□ 途中で確認を求められて止まる
→ 承認モードが都度承認になっています。安全な作業に限り、実行時の設定を見直してください。
```
