# 🎁 乗り換え前セルフ診断チェックリスト

Claude CodeからCodexへ「乗り換える」「併用する」「様子見する」のどれが自分に合うか、5ステップで判定できるチェックリストです。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 上から順にチェックし、最後に出たYESの数で判定します。

```text
【乗り換え前セルフ診断チェックリスト】

■ ステップ1：今の困りごとを確認する
□ Claude Proの利用制限（5時間ごと・週次）に月2回以上引っかかっているか
→ YES: ステップ2へ進む
□ 上位プラン（Max 5x／20x）の料金が負担に感じるか
→ YES: ステップ2へ進む
□ 特に制限で困っていない
→ YES: 今は移行を急ぐ必要なし。このまま様子見でOK

■ ステップ2：移行できる資産の量を確認する
□ CLAUDE.md・MCP設定・Skills・Subagentsなど、移せる設定を5つ以上持っているか
→ YES: 移行の効果が出やすいタイプ
□ 設定がほぼ無く、ミニマルな使い方をしているか
→ YES: 移行の手間は小さい。気軽に試してよい

■ ステップ3：移行できない機能への依存を確認する
□ 細かいpermission allowlistで安全性を厳密に管理しているか
→ YES: Codexのsandboxでは同等の細かさが無い点に注意。移行は慎重に
□ ConfigChangeフックやOutput stylesを日常的に使っているか
→ YES: これらは移行できない。使用頻度が高いなら併用前提で検討する
□ 上記のような機能への依存が無い
→ YES: 移行のハードルは低い

■ ステップ4：チーム状況を確認する
□ チームメンバーの一部がすでにCodexに興味を持っているか
→ YES: パイロット導入の相談相手になりうる
□ チーム全員がClaude Codeに強くこだわっているか
→ YES: 個人検証にとどめ、チーム展開は急がない

■ ステップ5：コスト許容度を確認する
□ 月6,500円程度（併用想定）まで許容できるか
→ YES: 併用を選択肢に入れられる
□ コストは今より増やしたくない
→ YES: まずは無料範囲・同額プランでの切り替えのみ検討する

【判定の目安】
YESが多く、特にステップ1・2でYESが出た場合 → 積極的に試す価値あり
ステップ3でYESが多い場合 → 併用（設定同期）を前提に検討する
ステップ4・5でYESが少ない場合 → 個人検証からスモールスタートする
```
