### 1. カスタム指示コピペテンプレート集（テンプレート）

# 🎁 カスタム指示コピペテンプレート集

ChatGPT Workの「カスタム指示」欄にそのまま貼れる、目的別のテンプレート6種です。

**受け取り方**: 各項目のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 設定 → パーソナライズ → カスタム指示 の欄に貼り付けてください。複数の要素を組み合わせて使っても構いません。

## 1. 汎用「右腕」カスタム指示

はじめての人向け。まずはこれを設定すれば安全に使い始められる基本セット。

```text
回答は日本語でお願いします。
指示していないファイルやフォルダは勝手に編集・削除しないでください。
既存のファイルを上書きする、または削除する前は、必ず一度私に確認してください。
作業の途中経過は、要点だけ簡潔に報告してください。長い説明は不要です。
分からないこと・判断に迷うことがあれば、進める前に必ず質問してください。
数字・日付・固有名詞を扱うときは、間違いがないか一度見直してから提出してください。
```

## 2. 秘書・スケジュール管理特化

カレンダーやメールを任せる「秘書」役として使うときの指示セット。

```text
あなたは私の秘書として、スケジュール調整・メール対応・タスク整理をサポートしてください。
社外の人へメールを送る前は、必ず下書きを見せて私の承認を得てから送信してください。
日程調整では、私の既存の予定と重複しないか必ず確認してください。
相手の役職・関係性に応じて、敬語のレベルを適切に調整してください。
緊急度の高い連絡（クレーム・トラブル）が来た場合は、他の作業より優先して私に知らせてください。
```

## 3. 経理・数字系特化（ミス防止重視）

金額・請求書など数字を扱う作業で、ミスを防ぐための指示セット。

```text
金額・日付・取引先名などの数字や固有名詞は、必ず元データと突き合わせてダブルチェックしてから報告してください。
合計値を出すときは、内訳の合計と一致しているか検算してください。
少しでも数字が不確かな場合は、断定せずに「要確認」と明記してください。
経費・請求に関する社外送付物は、必ず私の最終確認を経てから送信・提出してください。
金額の桁数（万・億の間違い等）には特に注意してください。
```

## 4. マーケティング・SNS特化

SNS投稿・広告文など、対外発信を任せるときの指示セット。

```text
SNSやブログへの投稿文を作るときは、装飾的な絵文字は使わず、機能的な記号（数字・矢印等）のみにしてください。
誇張表現・断定しすぎる表現（「絶対」「必ず効果がある」等）は避けてください。
薬機法・景品表示法に触れる可能性のある表現がないか、作成後に自己チェックしてください。
競合や他社を批判・比較する表現は避け、自社の価値を伝える言い回しにしてください。
公開・投稿の実行は必ず私の確認を経てから行ってください。下書きの提示までにとどめてください。
```

## 5. データ分析特化

ダッシュボード作成やレポート集計を任せるときの指示セット。

```text
データを集計するときは、集計期間・対象範囲を必ず明記してください。
異常値や欠損データを見つけた場合は、除外せずに一旦報告してから対応方針を確認してください。
グラフ・ダッシュボードを作るときは、数値の単位（円・千円・万円等）を必ず明示してください。
分析結果に個人の推測を含める場合は、事実（データ）と推測をはっきり分けて記述してください。
公開・共有する前に、内部限定の情報が含まれていないか確認してください。
```

## 6. 安全重視（誤操作防止・厳しめ）

権限をやや広めに使う場面で、誤操作のリスクを抑えたい人向けの厳格セット。

```text
ファイルの削除、上書き、外部への送信・投稿・公開は、いかなる場合も必ず事前に私の明示的な承認を得てから実行してください。
指定したワークスペース・フォルダの外にあるファイルには一切アクセスしないでください。
ネットワークへのアクセスが必要な操作（外部APIの呼び出し・パッケージのインストール等）は、その都度理由を説明し、承認を得てから行ってください。
複数のファイルにまたがる一括変更を行う前は、変更内容の一覧を先に見せてください。
少しでもリスクがあると感じた操作は、実行せずに私に判断を委ねてください。
```


### 2. 自分の業務をスキル化する手順書（ワークフロー）
# 自分の日常業務を、ChatGPT Workの「スキル」として再現できる形にするための判断シートです。

# 🎁 自分の業務をスキル化する手順書

自分の日常業務を、ChatGPT Workの「スキル」として再現できる形にするための判断シートです。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 手元に置いて、ステップ1から順にチェックしながら進めてください。

```text
【自分の業務をスキル化する手順書】

■ ステップ1：スキル化する作業を選ぶ
□ 週に1回以上、同じ手順で繰り返している作業か
□ 手順が毎回ほぼ同じ（判断が複雑すぎない）か
→ YES: その作業をそのままChatGPT Workにやらせてみる
指示例: 「〇〇を、いつもの手順でやってください」

■ ステップ2：実際に1回やらせてみる
□ 期待通りの結果になったか
□ 途中で余計な確認や誤操作がなかったか
→ YES: その流れをスキル化する
指示例: 「今の作業の流れをスキルにしてください」

■ ステップ3：呼び出し名を決める
□ 短く覚えやすい名前になっているか
□ 他のスキルと紛らわしくないか
→ YES: 名前を伝えて保存を依頼する
指示例: 「このスキルの名前は『〇〇』にしてください」

■ ステップ4：再現テストする
□ 別の日・別のデータで同じスキルを呼び出して試したか
□ 結果が安定して同じ形式で返ってきたか
→ YES: 日常的に使い始めてOK
指示例: 「/〇〇 でもう一度実行してください」

■ ステップ5：定期的に見直す
□ 業務のやり方が変わっていないか
□ スキルの手順が古くなっていないか
→ YES: 半年に1回を目安に更新する
指示例: 「このスキルの手順を、今のやり方に合わせて更新してください」
```

**ポイント**: 最初から完璧な手順書を目指さず、まず1回動かしてから育てる感覚で進めてください。


### 3. 領収書整理スキルのひな形（テンプレート）
# フォルダ内の領収書画像を日付・店名・金額で整理し、CSV台帳まで作らせるスキルのひな形です。

# 🎁 領収書整理スキルのひな形

フォルダ内の領収書画像を日付・店名・金額で整理し、CSV台帳まで作らせるスキルのひな形です。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: ChatGPT Workで「このスキルを保存して」と伝えて貼り付けるか、スキル作成画面にそのまま貼り付けてください。

```text
名前: レシートオーガナイザー
説明: 指定フォルダ内の領収書画像を日付・店名・金額で読み取り、ファイル名を整えてCSV台帳を作る。

手順:
1. 指定フォルダ内の画像を1枚ずつ開き、日付・店名・金額・品目を読み取る。
2. ファイル名を「YYYYMMDD_店名_金額」の形式に変更する。
3. 同じフォルダにCSVファイルを作り、日付/店名/金額/カテゴリの列で一覧化する。
4. カテゴリは交通費・飲食費・消耗品費・その他から判断して割り振る。
5. 読み取れなかった画像があれば、ファイル名の先頭に「要確認_」を付けて報告する。

呼び出し方: このスキルを保存したら、フォルダに画像を入れて /レシートオーガナイザー と送るだけで実行されます。
```

**ポイント**: 最初の数回は結果をそのまま経理提出せず、必ず自分の目で見直してから使ってください。

## 経理・請求書

### 1. 領収書フォルダの一括整理

スマホで撮った領収書画像フォルダを渡すだけで、日付・店名・金額を読み取りファイル名を統一し、CSV表まで作らせる。

```text
このフォルダの中の領収書画像を1枚ずつ確認し、日付(YYYYMMDD)・店名・金額が分かるファイル名に変更してください。同じフォルダにcsvファイルを作り、日付/店名/金額/カテゴリの列で一覧化してください。カテゴリは交通費・飲食費・消耗品費・その他から判断して割り振ってください。
```

### 2. 月次経費レポートの下書き

月末に領収書CSVから経費レポートのドラフトを作らせ、部門予算との差分も出させる。

```text
先ほど作成した経費CSVを元に、今月の経費レポートを作成してください。カテゴリ別の合計、先月比の増減、予算オーバーしている項目があれば赤字で注記してください。
```

### 3. 請求書の内容チェック

受け取った請求書PDFの記載内容を、発注書・契約条件と突き合わせて食い違いを検出させる。

```text
このフォルダにある請求書PDFと発注書PDFを突き合わせ、金額・品目・数量に食い違いがないか確認してください。食い違いがあれば該当箇所を引用して一覧にしてください。
```

### 4. 経費精算の期日リマインド

毎月決まった日に経費精算の締切をリマインドさせ、未提出の領収書がないか確認させる。

```text
毎月25日の朝9時に、今月分の領収書フォルダを確認し、まだCSVに反映されていない画像が残っていないかチェックして、私に結果を知らせるスケジュールを作ってください。
```

### 5. 交通費精算の自動計算

訪問先リストと出発地から、交通費精算に必要な区間・金額をまとめさせる。

```text
今月の訪問先一覧（会社名と住所）を渡すので、自宅からの往復交通費を経路ごとに調べて、精算用の一覧表（訪問日・訪問先・区間・金額）を作ってください。
```

### 6. 固定費の見直し提案

契約中のサブスク・固定費一覧を洗い出し、重複や使っていないものを指摘させる。

```text
このフォルダの契約書・請求書から、毎月発生している固定費（サブスクリプション・リース等）を一覧化し、用途が重複していそうなもの、直近3か月使用実績が見当たらないものを指摘してください。
```

### 7. 見積書テンプレートの作成

過去の見積書を参考に、新しい案件用の見積書フォーマットを作らせる。

```text
このフォルダにある過去の見積書3件を参考に、共通のフォーマット（会社ロゴ位置・項目構成・税表示）を抽出し、新規案件用の見積書テンプレートをスプレッドシートで作ってください。
```

### 8. 入金消込の確認

銀行の入出金明細と請求リストを突き合わせ、未入金の取引先を洗い出させる。

```text
この入出金明細CSVと請求書一覧を突き合わせて、入金が確認できていない請求書を一覧にしてください。取引先名・請求金額・請求日・経過日数を含めてください。
```

### 9. 年末調整資料の整理

1年分の領収書・控除証明書を種類別に仕分けし、年末調整用リストを作らせる。

```text
このフォルダの1年分の領収書・証明書PDFを、社会保険料控除・生命保険料控除・医療費控除などの種類ごとに仕分けし、それぞれの合計金額が分かる一覧を作ってください。
```

### 10. 経費規定違反のチェック

社内の経費規定PDFを読ませ、提出された経費申請が規定内かをチェックさせる。

```text
この経費規定PDFの内容を踏まえて、今月の経費申請一覧の中に規定の上限額を超えている、または対象外カテゴリに分類されている項目がないか確認してください。
```
