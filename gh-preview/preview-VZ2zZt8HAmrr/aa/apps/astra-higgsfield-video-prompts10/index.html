# 🎁 静止画1枚が“動く広告”になる Astra×HiggsField 動画生成プロンプト10選

Astraで下地の静止画を作り、それをHiggsFieldに渡して数秒の動画にする——この2段構えで、SNS広告・YouTubeのイントロ・商品紹介クリップがカメラなしで作れる10本です。各項目は「①Astraへ渡す静止画プロンプト」と「②HiggsField側のカメラ・モーション設定」をセットにしてあるので、順番に貼るだけで動きます。

**受け取り方**: 下の各コードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: まず①をAstraに貼って静止画を書き出す→HiggsFieldで新規プロジェクトを作り、その画像を開始フレームに設定→②のカメラプリセット・モーション強度・尺を入れて生成。プリセット名はサービス更新で変わることがあるので、②では「動きの中身」も併記してあります。

## 1. 商品を1周見せる360°プロダクト動画

```text
期待できるメリット: 物撮り＋ターンテーブル動画を外注すると数万円かかるところを、静止画1枚から回転動画にできる。EC・LPの離脱を減らせる。
使う場面: 単体の商品（ボトル、ガジェット、パッケージ等）を全方位から見せたいとき。
① Astraへ渡す静止画プロンプト:
（Astraへ）商品の正面カット画像を1:1で作ってください。被写体は「（例：マットな質感の黒いステンレスボトル）」。無地の淡いグレー背景、真正面・アイレベル、柔らかい面光源を斜め上から当てて自然な落ち影。反射は控えめ。商品だけを画面中央に大きく、周囲に均等な余白。文字・ロゴは入れない。実写風。
② HiggsFieldでの設定（開始フレーム＝①の画像）:
・カメラ: 「360 Orbit」系プリセット（被写体を中心に水平に1周ぐるりと回り込む動き）。無ければ「Orbit Left」で半周＋逆再生でループ化。
・モーション強度: 中（背景が破綻しない範囲）。
・尺: 4〜6秒。
・仕上げ指示: 被写体の形は変えず、背景のグレーは均一に保つ。手ブレ風の揺れは入れない。
つまずきどころ: 背景に模様や小物があると回り込みで歪む。①の時点で「無地・小物なし」を徹底する。強度を上げすぎるとラベルの文字が溶けるので中どまりにする。
```

## 2. スクロールを止めるSNS広告の3秒フック

```text
期待できるメリット: 冒頭3秒で指を止めさせる“動きの強い”クリップが作れる。静止画バナーより広告のクリック率が上がりやすい。
使う場面: Instagram/TikTok/YouTubeショートの広告で、最初のカットに使う短尺素材が欲しいとき。
① Astraへ渡す静止画プロンプト:
（Astraへ）縦型9:16の画像を作ってください。被写体は「（例：机に山積みの書類の前で頭を抱える会社員）」。手前は少しボケ、奥にピント。色は寒色で重い雰囲気。上3分の1と下3分の1はテキストを載せるため暗めに空ける。実写風、ドラマのワンシーンのような照明。文字は入れない。
② HiggsFieldでの設定（開始フレーム＝①の画像）:
・カメラ: 「Crash Zoom In」系（被写体へ一気に速く寄る）。無ければ「Fast Dolly In」。
・モーション強度: 強め。
・尺: 3秒。
・仕上げ指示: 被写体の姿勢は保ったまま、カメラだけが急接近する。最後の0.5秒は動きを止めてテキストを載せられるようにする。
つまずきどころ: 人物の指や顔が動きすぎると不気味になる。「姿勢は保つ、動くのはカメラ」と必ず指定。尺を伸ばすと失速するので3秒固定が安全。
```

## 3. YouTube動画のイントロ／アウトロのブランドモーション

```text
期待できるメリット: 毎回同じ数秒のオープニングが用意でき、チャンネルの“顔”になる。モーショングラフィックスの外注（1本数万円）が不要。
使う場面: 動画の冒頭3〜5秒、またはエンドカードの背景として繰り返し使う共通素材。
① Astraへ渡す静止画プロンプト:
（Astraへ）16:9の抽象的な背景画像を作ってください。濃紺からシアンへのグラデーションに、細い光の線が中央から放射状に伸びる。中央は文字（チャンネル名）を載せるため落ち着かせ、光は外周に集める。質感はマット＋弱いノイズ。具体的な物や文字は描かない。落ち着いた先進的な雰囲気。
② HiggsFieldでの設定（開始フレーム＝①の画像）:
・カメラ: 「Dolly In」系（正面からゆっくり前進）＋わずかな時計回りの回転。
・モーション強度: 弱〜中。
・尺: 5秒。
・仕上げ指示: 光の線がゆっくり脈打つように動く。中央の暗い部分は動かさず安定させる（テキストを重ねるため）。ループ再生しても違和感が出ないよう、始点と終点の明るさを揃える。
つまずきどころ: 動きを付けすぎると毎回の視聴で飽きる。「弱〜中」で上品に。中央が動くとタイトルが読みづらいので必ず固定を指示する。
```

```text
（Astraへ）人物のバストアップ画像を16:9で作ってください。30代の日本人、ビジネスカジュアル、正面を向き穏やかな表情で軽く微笑む。背景は明るいオフィスを浅くぼかす。自然光、加工感は控えめ、実写風。特定の有名人に似せない。文字・ロゴは写さない。
② HiggsFieldでの設定（開始フレーム＝①の画像）:

・仕上げ指示: 体の位置・服装・背景は固定。動かすのは口・目・わずかな頭の傾きだけ。手は画面に入れない。
つまずきどころ: 長尺を一度に作ると途中で顔が崩れる。10秒前後で区切って生成し、編集でつなぐ。手を映すと指の破綻が目立つのでバストアップに収める。
```

```text
期待できるメリット: 導入前後・加工前後の変化を“切り替わる映像”で見せられる。左右並べた静止画より印象に残りやすい。
使う場面: ビフォーアフターを1カットで見せたい商品紹介・実績紹介。
① Astraへ渡す静止画プロンプト:
（Astraへ）同じ画角の画像を2枚作ってください。1枚目（Before）は「（例：雑然として暗いワークスペース）」、2枚目（After）は「同じ場所が片付いて明るいワークスペース」。カメラ位置・画角・家具の配置は完全に同じで、状態と光だけを変える。実写風、フラットで見やすいトーン。文字は入れない。
② HiggsFieldでの設定:
・開始フレーム＝Before、終了フレーム＝Afterに設定（start/end frame機能）。
・カメラ: ほぼ固定＋ごく弱いズームイン。
・モーション強度: 弱。
・尺: 3〜4秒。
・仕上げ指示: BeforeからAfterへ自然に遷移させる。物が瞬間移動したように見えないよう、明るさの変化を主役にする。
つまずきどころ: 2枚の画角がずれると遷移がガタつく。Astra側で「カメラ位置・画角・配置は完全に同じ」を必ず指定。end frame機能がない場合は、Before/Afterを別々に短く動かして編集でクロスディゾルブする。
```

## 10. カメラプリセットを主役にしたドラマチックな1カット

```text
期待できるメリット: 手持ちでは不可能な大胆なカメラワーク（急旋回・持ち上げ・寄り引き）が1枚の静止画から得られる。動画の“見せ場”を安く作れる。
使う場面: オープニングの1発目や、商品・場所を印象的に登場させたいとき。
① Astraへ渡す静止画プロンプト:
（Astraへ）16:9の画像を作ってください。被写体は「（例：ビル屋上に立ち、街を見下ろす人物の後ろ姿）」。夕方の斜光、逆光で人物はシルエット気味、空はオレンジから紫のグラデーション。手前に屋上のフェンス、奥に街並み。実写風、映画のポスターのような色設計。文字なし。
② HiggsFieldでの設定（開始フレーム＝①の画像）:
・カメラ: 「Crane Down」または「Robo Arm」系（被写体の背後から回り込みつつ持ち上がる、または大きく弧を描く動き）。
・モーション強度: 中〜強。
・尺: 4〜5秒。
・仕上げ指示: 人物は動かさず立ち姿を保つ。カメラだけが弧を描いて回り込む。空のグラデーションと街の輪郭は破綻させない。
つまずきどころ: 強いカメラワークは背景の破綻と引き換え。空・遠景などディテールの少ない構図を①で選ぶと成功率が上がる。1回で決まらない前提で3テイク回す。
```

**ポイント**: HiggsFieldは「カメラを動かす／被写体は動かさない」と割り切るほど破綻しません。人物の手・指・文字は崩れやすいので、①の静止画の段階でそれらを画面に入れない構図を選んでください。プリセット名が見つからないときは、各項目の「動きの中身」の説明をそのまま自由入力欄に貼れば近い結果になります。
