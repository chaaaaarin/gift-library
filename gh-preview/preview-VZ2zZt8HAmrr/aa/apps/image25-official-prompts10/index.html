# 🎁 【公式ベース】Image 2.5 で“作り直しゼロ”になるプロンプト10選

ChatGPT の新画像モデル Image 2.5 は「一部だけ直す」「透過で切り抜く」「参照写真の人物・商品を崩さない」が一気に得意になりました。公式が示す使い方（用途→構図→ディテール→変える所と残す所を分ける）に沿って、仕事でそのまま使う10本にしてあります。1枚あたり15〜40分かかっていた素材づくりと直しの往復が、5分＋1回の微修正で終わります。

**受け取り方**: 下の各コードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 1〜5は「今ある画像を直す」系（写真をドラッグして貼ってから実行）、6〜10は「ゼロから作る」系です。プロンプト内の「16:9」「1:1」などの比率、色、除外条件だけ自分の案件に置き換えれば動きます。ChatGPT の無料枠でも使えます。

## 1. 商品を透過背景で完璧に切り抜く（EC・LP・提案資料）

```text
期待できるメリット: 切り抜き作業の外注（1点500〜1500円）や自分での手作業が要らなくなる。髪の毛・グラス・影の境目まで抜けるので、そのままLPやバナーに置ける。
使う場面: 撮った商品写真をECサイト・提案資料・広告バナーに載せる直前、背景を消したいとき。
前提: 商品が写った写真を1枚チャットにドラッグして添付してある。
そのまま貼るプロンプト:
（ChatGPTへ）添付画像の商品だけを抜き出し、完全な透過背景に配置してください。PNG形式。商品の形・色・質感・ラベルの文字は一切変えない。単色の背景・チェッカー模様・床・影・小物は足さない。商品は中央に置き、上下左右に均等な余白を10%とる。輪郭のギザつきや白フチが残らないようにする。
調整のコツ: バナー用に影がほしいときは、切り抜いたあとに続けて「真下に柔らかい楕円形の影を薄く1つだけ足して」と別ターンで頼む。最初から影ありで頼むと背景ごと作られやすい。
つまずきどころ: 出力後、拡大して髪・毛・透明パーツの縁に背景色が残っていないか必ず確認する。残っていたら「縁に残った背景色を消して、アルファチャンネルをきれいにして」ともう一度かける。
```

## 2. 顔・体型を変えずに服だけ着せ替える（アパレルEC・人物差し替え）

```text
期待できるメリット: モデルの追加手配なしで、1回の写真から複数コーデのカットが作れる。Image 2.5 は顔と体型の保持が強くなったので、別人になりにくい。
使う場面: アパレルECの商品ページ、コーデ提案、人物写真の服だけ差し替えたいとき。
前提: 人物が写った元画像と、着せたい服の画像を2枚ともチャットに添付してある。
そのまま貼るプロンプト:
（ChatGPTへ）1枚目の人物に、2枚目の服を着せてください。変えるのは服だけ。顔・髪型・肌の色・体型・姿勢・立ち位置・背景・照明・写真の色味は1枚目のまま一切変えない。服のサイズ感とシワは体に自然に合わせる。2枚目の服の色・柄・素材感は正確に再現する。文字やロゴを勝手に足さない。
調整のコツ: 複数コーデを作るときは、1枚目の人物画像を毎回同じものに固定し、2枚目だけ差し替える。「1枚目のまま」と毎ターン書き直すと同一人物を保ちやすい。
つまずきどころ: 何度も編集を重ねると顔が少しずつずれる。3回直したら一度、最初の人物画像から作り直す。手や指が乱れたら「手と指だけ自然な形に直して、他は変えない」で部分修正する。
```

## 3. 写真から不要なものだけ消す（電線・通行人・写り込み）

```text
期待できるメリット: レタッチソフトのスタンプ作業が要らない。「これだけ消して、他はそのまま」が通るので、背景が複雑でも破綻しにくくなった。
使う場面: 物件写真・商品写真・イベント写真から、電線・通行人・生活感のあるもの・写り込んだ関係者を消したいとき。
前提: 対象が写った写真を1枚添付してある。消したいものを言葉で特定できる。
そのまま貼るプロンプト:
（ChatGPTへ）添付画像から「（例：画面右奥の赤い看板と、その下を歩く2人の通行人）」だけを消してください。消したあとは周囲の壁・地面・空と自然につながるように埋める。それ以外の部分（構図・色・明るさ・他の被写体・影・遠近感）は一切変えない。新しい物や文字を足さない。
調整のコツ: 消す対象は位置＋色＋形で指定すると精度が上がる（「右の物」より「右奥の赤い看板」）。複数あるときは1回で全部言わず、1つ消す→確認→次を消す、と分ける。
つまずきどころ: 消した跡がぼやけたり不自然な模様になったら、「消した部分を、まわりの◯◯（例：レンガの壁）と同じ質感で埋め直して」と追いプロンプトする。
```

## 4. 室内・空間写真の一部だけ差し替える（内装・什器の提案）

```text
期待できるメリット: 「この椅子を木製にしたら」「この壁を白にしたら」を、撮り直しやCGなしで見せられる。カメラ位置と光が保たれるので、before/afterとして並べられる。
使う場面: 店舗・オフィス・住宅の内装提案、家具の入れ替えシミュレーション、施工前の合意形成。
前提: 対象の空間写真を1枚添付してある。
そのまま貼るプロンプト:
（ChatGPTへ）この部屋の写真で、「（例：白いパイプ椅子）」だけを「（例：明るいオーク材の木製チェア）」に置き換えてください。変えるのはその対象だけ。カメラアングル・部屋の広さ・床・壁・窓・照明の当たり方・影の向き・全体の色味は元のまま保つ。新しい家具のサイズは元の対象と同じスケールに合わせ、床にきちんと接地させる。
調整のコツ: 提案の比較用に、まず「置き換えなし（元画像）」と「置き換えあり」をセットで出す。素材違いを複数見せるなら、対象の指定文を固定して「オーク材／ウォルナット／スチール」と語尾だけ変える。
つまずきどころ: 複数の物を一度に変えると他の部分まで動く。1物1ターンで。影の向きがおかしくなったら「窓からの光の向きは元画像に合わせて、影を付け直して」で修正。
```

## 5. 参照画像のトーンを引き継いで別カットを量産する（シリーズ画像）

```text
期待できるメリット: 1枚“正解”を作れば、同じ世界観のカットを何枚でも増やせる。資料の挿絵・SNSの連投・記事のアイキャッチが、回を追うごとにバラバラにならない。
使う場面: スライドの章扉、連載記事のアイキャッチ、SNSのシリーズ投稿など、複数枚を同じ見た目でそろえたいとき。
前提: 見本にしたい画像を1枚添付してある（過去に自分で作った・撮った画像でよい）。
そのまま貼るプロンプト:
（ChatGPTへ）添付画像を「スタイルの見本」として使ってください。この画像から、配色・線の太さ・質感・光の雰囲気・余白の取り方だけを引き継ぎ、モチーフは「（例：ノートPCとコーヒーカップのある机）」に変えて16:9で描いてください。見本の構図や被写体そのものはコピーしない。文字は入れない。
調整のコツ: 2枚目以降は「同じスタイルの見本のまま、次はこのモチーフ」と、モチーフ名だけ差し替えて続ける。気に入ったスタイルの画像は名前を付けて保存し、毎回の見本として使い回す。
つまずきどころ: 「見本の色と質感だけ」と範囲を絞らないと、構図まで似てしまう。逆に似ないときは「見本の“塗り方”をもっと忠実に真似て」と踏み込む。
```

## 6. 仕組み・処理の流れを1枚のインフォグラフィックにする

```text
期待できるメリット: 口頭やテキストで説明していた仕組みが、1枚の図で伝わる。作図ツールでゼロから箱と矢印を並べる30分〜1時間が省ける。
使う場面: サービスの裏側・業務フロー・機械や仕組みの動作を、提案資料や記事で説明したいとき。
前提: 説明したい流れを、工程の順に自分の言葉で書き出せる。
そのまま貼るプロンプト:
（ChatGPTへ）インフォグラフィックを16:9で作ってください。テーマは「（例：問い合わせが入ってから一次回答が返るまでの流れ）」。工程は左から右へ順番に並べる：（1）◯◯ →（2）◯◯ →（3）◯◯ →（4）◯◯。各工程は角丸の箱にアイコンを1つ添え、矢印でつなぐ。配色は白背景＋濃紺の線、重要な1工程だけ山吹色で強調。フラットな平面デザイン、影は最小限。box内の短いラベル（各6文字以内）は正確に表示し、それ以外の余計な文字は入れない。
調整のコツ: 工程は4〜6個までに絞る。7個以上あるなら「2段組みにして」と指定する。ラベルの日本語が乱れたら英数字だけにするか、「ラベルは空にして」と頼んで後から自分で入れる。
つまずきどころ: 一度に全部の要素（凡例・注釈・タイトル・小見出し）を盛ると崩れる。まず「箱＋矢印＋短いラベル」だけ作り、タイトルや注釈は別ターンで足す。
```
