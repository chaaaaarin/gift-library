### 1. ccusage 毎朝ミニ通知（cost-watch.sh + cron/launchd）（テンプレート）
# `ccusage` を毎朝1回だけ自動で回して、「今月の推定コスト」と「昨日いくら使ったか」をデスクトップ通知＋ログ1行で受け取れます。自分から数字を見に行かなくても、使いすぎに毎朝気づける状態になります。ccusage 本体は `npx` でその場実行なのでインストール不要です。

# 🎁 ccusage 毎朝ミニ通知（cost-watch.sh + cron/launchd）

`ccusage` を毎朝1回だけ自動で回して、「今月の推定コスト」と「昨日いくら使ったか」をデスクトップ通知＋ログ1行で受け取れます。自分から数字を見に行かなくても、使いすぎに毎朝気づける状態になります。ccusage 本体は `npx` でその場実行なのでインストール不要です。

**受け取り方**: このファイルをダウンロードするか、下のコードブロック右上のコピーボタンで受け取ってください。

**使い方**:
1. `cost-watch.sh` を `~/.claude/cost-watch.sh` に保存
2. 一度手で `bash ~/.claude/cost-watch.sh` を実行して、通知とログ（`~/.claude/cost-watch.log`）が出るか確認
3. 毎朝走らせる（下の「毎朝の登録」）
4. やめるとき: cron なら `crontab -e` で該当行を削除／launchd なら `launchctl unload ~/Library/LaunchAgents/com.local.claude-cost-watch.plist`

## ① cost-watch.sh

```text
#!/bin/bash
# ccusage を1回回して「今月の推定コスト」と「昨日分」を通知＋ログに残す
LOG="$HOME/.claude/cost-watch.log"
TODAY=$(date +%Y-%m-%d)
YDAY=$(date -v-1d +%Y-%m-%d 2>/dev/null || date -d "yesterday" +%Y-%m-%d)
MONTH=$(date +%Y-%m)

# ccusage の日次を JSON で取得（インストール不要）
JSON=$(npx -y ccusage@latest daily --json --since "${MONTH}-01" 2>/dev/null)
if [ -z "$JSON" ]; then
  echo "$TODAY  ccusage 取得失敗" >> "$LOG"
  exit 1
fi

# 今月合計と昨日分を jq で集計（キー名の揺れに備えて複数候補を見る）
MONTH_COST=$(printf '%s' "$JSON" | jq -r '
  ([.daily[]? // .[]? | (.totalCost // .cost // .total_cost // 0)] | add) // 0' 2>/dev/null)
YDAY_COST=$(printf '%s' "$JSON" | jq -r --arg d "$YDAY" '
  (([.daily[]? // .[]? | select((.date // .day // "") | startswith($d))] | .[0])
   | (.totalCost // .cost // .total_cost // 0)) // 0' 2>/dev/null)

MONTH_COST=$(printf '%.2f' "${MONTH_COST:-0}" 2>/dev/null || echo "${MONTH_COST:-0}")
YDAY_COST=$(printf '%.2f' "${YDAY_COST:-0}" 2>/dev/null || echo "${YDAY_COST:-0}")

MSG="今月の推定コスト \$${MONTH_COST}（昨日 \$${YDAY_COST}）"
echo "$TODAY  $MSG" >> "$LOG"

# 通知（OS別）
case "$(uname -s)" in
  Darwin) osascript -e "display notification \"$MSG\" with title \"Claude Code コスト\"" ;;
  Linux)  command -v notify-send >/dev/null && notify-send "Claude Code コスト" "$MSG" ;;
  *)      powershell -c "Write-Output '$MSG'" ;;
esac
```

## ② 毎朝の登録

**macOS / Linux（cron・毎朝9時）**

`crontab -e` を開いて、次の1行を足します。

```text
0 9 * * * /bin/bash "$HOME/.claude/cost-watch.sh"
```

**macOS（launchd で確実に・毎朝9時）**

`~/Library/LaunchAgents/com.local.claude-cost-watch.plist` を作って、`launchctl load ~/Library/LaunchAgents/com.local.claude-cost-watch.plist` で有効化します。

```text
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key><string>com.local.claude-cost-watch</string>
  <key>ProgramArguments</key>
  <array>
    <string>/bin/bash</string>
    <string>-c</string>
    <string>"$HOME/.claude/cost-watch.sh"</string>
  </array>
  <key>StartCalendarInterval</key>
  <dict><key>Hour</key><integer>9</integer><key>Minute</key><integer>0</integer></dict>
  <key>RunAtLoad</key><false/>
</dict>
</plist>
```

**ポイント**: 表示される金額はすべて **API 単価換算の推定額**です。定額プラン（Pro / Max）の実際の請求額とは一致しません。「今月これくらい使うペースだな」という傾向を掴む用途に使ってください。`ccusage` のバージョンで JSON のキー名が変わることがあるので、通知に `$0.00` しか出ないときは `npx -y ccusage@latest daily --json | jq` で実際のキー名を確認し、`cost-watch.sh` の `.totalCost // .cost` の部分を合わせてください。

### 3. Claude Code 見える化スターター（statusline.sh + settings.json + setup.sh）（テンプレート）
# `setup.sh` を1回叩くだけで、画面下に「残りコンテキスト・コスト・経過時間・ブランチ」が常時表示され、入力待ち・完了でデスクトップ通知が飛ぶようになります。ccstatusline を入れなくても `jq` だけで動く自己完結スクリプトなので、依存が増えません。合わなければ `bash setup.sh undo` で元通り（settings.json はバックアップから復元）。

# 🎁 Claude Code 見える化スターター（statusline.sh + settings.json + setup.sh）

`setup.sh` を1回叩くだけで、画面下に「残りコンテキスト・コスト・経過時間・ブランチ」が常時表示され、入力待ち・完了でデスクトップ通知が飛ぶようになります。ccstatusline を入れなくても `jq` だけで動く自己完結スクリプトなので、依存が増えません。合わなければ `bash setup.sh undo` で元通り（settings.json はバックアップから復元）。

**受け取り方**: このファイルをダウンロードするか、下の各コードブロック右上のコピーボタンで1つずつ受け取ってください。

**使い方**:
1. `jq` を入れる（`brew install jq` / `sudo apt install jq` / `winget install jqlang.jq`）
2. 下の `setup.sh` を保存して `bash setup.sh` を実行（`~/.claude/statusline.sh` を作成し、`~/.claude/settings.json` に `statusLine` と通知フックを追記。実行前に `settings.json.bak-visukit` を作ります）
3. Claude Code を再起動
4. 戻すとき: `bash setup.sh undo`

## ① setup.sh（これだけ実行すればOK）

```text
#!/bin/bash
# Claude Code 見える化スターター セットアップ
set -e
CDIR="$HOME/.claude"
SL="$CDIR/statusline.sh"
CFG="$CDIR/settings.json"
BAK="$CFG.bak-visukit"
mkdir -p "$CDIR"

if [ "$1" = "undo" ]; then
  if [ -f "$BAK" ]; then mv "$BAK" "$CFG"; echo "settings.json をバックアップから戻しました"; fi
  if [ -f "$SL" ]; then rm "$SL"; echo "statusline.sh を削除しました"; fi
  echo "完了。Claude Code を再起動してください。"
  exit 0
fi

command -v jq >/dev/null || { echo "jq が必要です: brew install jq / sudo apt install jq / winget install jqlang.jq"; exit 1; }

# 1) statusline.sh を書き出す
cat > "$SL" <<'STATUSLINE'
#!/bin/bash
# Claude Code 見える化 statusline —— jq だけで動く。~/.claude/statusline.sh に置く
input=$(cat)
j(){ printf '%s' "$input" | jq -r "$1" 2>/dev/null; }

MODEL=$(j '.model.display_name // "?"')
REMAIN=$(j '.context_window.remaining_percentage // empty')
USED=$(j '.context_window.used_percentage // empty')
COST=$(j '.cost.total_cost_usd // 0')
DUR_MS=$(j '.cost.total_duration_ms // 0')
DIR=$(j '.workspace.current_dir // .cwd // ""')
WT=$(j '.workspace.git_worktree // empty')
EFFORT=$(j '.effort.level // empty')
FAST=$(j '.fast_mode // false')

# 残りコンテキスト（remaining が無ければ used から算出）
if [ -z "$REMAIN" ] && [ -n "$USED" ]; then
  REMAIN=$(awk -v u="$USED" 'BEGIN{printf "%d",100-u}')
fi
REMAIN=${REMAIN%.*}

# 経過時間 m:ss
SECS=$(( DUR_MS / 1000 ))
printf -v CLOCK '%d:%02d' $(( SECS/60 )) $(( SECS%60 ))

# git ブランチ（未コミットがあれば * を付ける）
BR=""
if [ -n "$DIR" ] && git -C "$DIR" rev-parse --is-inside-work-tree >/dev/null 2>&1; then
  BR=$(git -C "$DIR" branch --show-current 2>/dev/null)
  [ -n "$(git -C "$DIR" status --porcelain 2>/dev/null)" ] && BR="${BR}*"
fi

# 色（残量が減るほど赤寄りに）
E=$'\033'; RST="${E}[0m"; DIM="${E}[2m"; ACC="${E}[38;5;173m"
r=${REMAIN:-100}
if   [ "$r" -le 15 ]; then CB="${E}[38;5;203m"
elif [ "$r" -le 35 ]; then CB="${E}[38;5;179m"
else CB="${E}[38;5;108m"; fi

SEP="${DIM} · ${RST}"
OUT="${ACC}${MODEL}${RST}"
[ -n "$REMAIN" ] && OUT="${OUT}${SEP}${CB}ctx ${REMAIN}%${RST}"
OUT="${OUT}${SEP}\$$(printf '%.2f' "$COST" 2>/dev/null || echo "$COST")"
OUT="${OUT}${SEP}${CLOCK}"
[ -n "$BR" ] && OUT="${OUT}${SEP}${BR}"
[ -n "$WT" ] && OUT="${OUT}${SEP}wt:${WT}"
[ -n "$EFFORT" ] && OUT="${OUT}${SEP}${EFFORT}"
[ "$FAST" = "true" ] && OUT="${OUT}${SEP}fast"
printf '%s' "$OUT"
STATUSLINE
echo "→ 作成: $SL"

# 2) settings.json に statusLine と通知フックを入れる（バックアップを取ってから）
OS=$(uname -s)
case "$OS" in
  Darwin)
    N_WAIT='osascript -e "display notification \"入力を待っています\" with title \"Claude Code\""'
    N_DONE='osascript -e "display notification \"作業が終わりました\" with title \"Claude Code\" sound name \"Glass\""' ;;
  Linux)
    N_WAIT='notify-send "Claude Code" "入力を待っています"'
    N_DONE='notify-send "Claude Code" "作業が終わりました"' ;;
  *)
    N_WAIT='powershell -c "[void][System.Reflection.Assembly]::LoadWithPartialName(\"System.Windows.Forms\");[System.Windows.Forms.MessageBox]::Show(\"入力を待っています\",\"Claude Code\")"'
    N_DONE='powershell -c "[void][System.Reflection.Assembly]::LoadWithPartialName(\"System.Windows.Forms\");[System.Windows.Forms.MessageBox]::Show(\"作業が終わりました\",\"Claude Code\")"' ;;
esac

[ -f "$CFG" ] || echo '{}' > "$CFG"
cp "$CFG" "$BAK"
jq --arg w "$N_WAIT" --arg d "$N_DONE" '
  .statusLine = {type:"command", command:"bash ~/.claude/statusline.sh"}
  | .hooks = (.hooks // {})
  | .hooks.Notification = [{matcher:"", hooks:[{type:"command", command:$w}]}]
  | .hooks.Stop = [{matcher:"", hooks:[{type:"command", command:$d}]}]
' "$BAK" > "$CFG"
echo "→ 更新: $CFG（バックアップ: $BAK）"
echo ""
echo "完了。Claude Code を再起動すると反映されます。"
echo "戻すとき: bash setup.sh undo"
```

## ③ settings.json に足すブロック（macOS の例。手で入れる場合）

`~/.claude/settings.json` にこの `statusLine` と `hooks` を入れます。すでに `hooks` がある場合は `Notification` / `Stop` を兄弟キーとして足してください。Linux は `notify-send "Claude Code" "…"`、Windows は PowerShell のトースト等に置き換えます。

```text
{
  "statusLine": {
    "type": "command",
    "command": "bash ~/.claude/statusline.sh"
  },
  "hooks": {
    "Notification": [
      { "matcher": "", "hooks": [
        { "type": "command", "command": "osascript -e 'display notification \"入力を待っています\" with title \"Claude Code\"'" }
      ]}
    ],
    "Stop": [
      { "matcher": "", "hooks": [
        { "type": "command", "command": "osascript -e 'display notification \"作業が終わりました\" with title \"Claude Code\" sound name \"Glass\"'" }
      ]}
    ]
  }
}
```

**ポイント**: 表示される `$` 金額は、定額プラン（Pro / Max）では API 単価換算の推定額で、実請求とは一致しません。`ctx 42%` は「残り」の割合です。`osascript` の通知が出ないときは、ターミナルで一度 `osascript -e 'display notification "test"'` を実行して、Script Editor に通知許可を与えてください。
