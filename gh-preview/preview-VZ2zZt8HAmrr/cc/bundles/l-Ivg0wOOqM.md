# 🎁 スケジュール実行レシピ50

「毎朝7時に〜して送って」のように、そのまま自然言語で頼めばスケジュール登録できる指示文です。朝の一括報告・定期リサーチ・締め切りリマインド・週次月次の棚卸し・開発運用の見回りの5分野×10本、計50本です。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 「指示」の文をそのままTelegram/Discord経由でClaude Codeに送るだけで、`CronCreate`によるスケジュール登録が行われます。時刻・頻度は自分の生活に合わせて書き換えてください。

## 朝の一括報告

### 1. 朝の予定・タスク一括報告

```text
前提: 毎朝バラバラに確認している予定とタスクを1本化したい人向け。
指示: 毎朝7時に、今日のGoogleカレンダーの予定と未完了タスクをまとめてTelegramに送って。
出力形式: 「予定（時刻順）」「今日のタスク」の2セクション。予定が0件の日は「予定なし」と明記して。
```

### 2. 朝の未読メール要約

```text
前提: 出社・始業前にメールの山を把握したい人向け。
指示: 毎朝7時30分に、前日夜から今朝までの未読メールを確認し、重要なものだけ要約して送って。
出力形式: 重要度上位3件を「送信者／件名／要点1行」で。0件の日は「新着なし」の一言で。
```

### 3. 朝のニュースダイジェスト

```text
前提: 毎朝の情報収集を自動化したい人向け。
指示: 毎朝8時に、指定した業界ニュースサイトの新着記事から重要なもの3件を選んで送って。
出力形式: 「見出し／要点1行／URL」のセットを3件、重要度順に並べて。
```

### 4. 朝の天気・移動時間チェック

```text

出力形式: 外出予定がある日のみ「天気」「移動時間の目安」を2行で。無い日は送らなくてよい。
```

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 「人格設定シート」を埋めた内容をそのままCLAUDE.mdに貼り付けてください。「セットアップチェックリスト」は上から順に実行し、□にチェックしながら進めてください。

```text
【CLAUDE.md 人格設定シート】

■ ステップ1：呼び方と口調を決める
□ 秘書に名前をつけたか
→ YES: CLAUDE.mdの冒頭に「あなたの名前は◯◯です」と書く
指示例: あなたの名前は「◯◯」です。以後この名前で振る舞ってください。

□ 口調は決まっているか（敬語／フランク／中間）
→ YES: 実際の言い回し例を1〜2文、そのままCLAUDE.mdに貼る
指示例: 口調は丁寧語ベースですが、絵文字や過度な敬語は使わないでください。「〜です」「〜します」で統一してください。

■ ステップ2：判断基準を決める
□ 「本人に確認してから動く」場面と「先に進めてよい」場面を分けたか
→ YES: 具体例を2〜3個挙げてCLAUDE.mdに書く
指示例: 金額が発生する判断・社外への返信は必ず確認を取ってください。日程の空き確認・情報のリサーチは確認なしで進めてよいです。

□ 一次対応の範囲を決めたか
→ YES: 「ここまでは秘書が答えてよい」の線引きを1〜2行で書く
指示例: 問い合わせには「確認して折り返します」まで秘書が返信してよいですが、具体的な回答は必ず本人の確認後にしてください。

■ ステップ3：自分の情報を渡す
□ よく使う連絡先・チーム構成を書いたか
→ YES: 名前・役割・連絡手段を一覧でCLAUDE.mdに書く
指示例: 主な関係者は次の通りです。◯◯さん（クライアントA担当）、△△さん（編集担当）。

□ 定型業務・繰り返しのパターンを書いたか
→ YES: 「毎週やること」「毎月やること」を箇条書きで書く
指示例: 毎週金曜には今週の進捗をまとめる習慣があります。フォーマットは「進んだこと／止まっていること」の2見出しです。

■ ステップ4：止めどきを決める
□ 秘書の対応を止めたいときの合図を決めたか
→ YES: 「一旦停止して」のような合図をCLAUDE.mdに明記する
指示例: 「ここまでで一旦止めて」と言われたら、それ以上は自動で進めず、次の指示を待ってください。

【Channels セットアップチェックリスト】
```

# 🎁 Claude Code秘書 依頼文100選

Telegram・DiscordからChannels経由で送るだけの依頼文です。「前提／指示／出力形式」の3点セットになっているので、そのままコピペで使えます。報告・調査・下書き・調整・整理の5分野×20本、計100本です。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 番号は通し番号です。カテゴリ見出しごとに20本ずつ並んでいます。文中の「（後述）」は、実際に使うときにその場の情報（カレンダーの中身・メモの内容など）に置き換えてください。

```text

指示: 今日のGoogleカレンダーの予定を全件取得し、開始時刻順に並べ替えて。会議は参加者名も添えて。
出力形式: 「時刻／件名／参加者（あれば）」の一覧を箇条書きで。空き時間帯も最後に1行でまとめて。
```

### 2. 未読メールの要点報告

```text
出力形式: 重要度が高い順に「送信者／件名／要点1行／重要度(高中低)」の表にまとめて。全て低ければ「緊急対応不要」の一言で。
```
