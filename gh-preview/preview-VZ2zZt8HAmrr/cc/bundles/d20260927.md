## Productivity（仕事を覚えさせる）

### 1. 最初の1回で、自分の仕事を丸ごと覚えさせる

説明: 毎回の前置きが要らなくなる初期設定。入れた直後に1回だけ使います。関係者や社内の略語まで覚えるので、2回目からは「〇〇さんの件」だけで通じます。うまく覚えないときは、人と略語を1行ずつに分けて書き直してください。

```text
/start
これから私の仕事を覚えて、やることリストと記憶を用意してください。

【私の仕事】
〔例：小さな雑貨の会社で、商品の企画と販売を担当しています〕

【よく出てくる人】
・〔名前〕：〔どういう人か。例：取引先のカフェのオーナー〕
・〔名前〕：〔どういう人か〕

【社内の呼び方】
・〔略語〕＝〔正式な名前〕
・〔略語〕＝〔正式な名前〕

【今やっていること】
1. 〔やること〕…〔期限〕
2. 〔やること〕…〔期限〕
3. 〔やること〕…〔期限・止まっていればその理由〕

終わったら、覚えた人・言葉・やることを表で見せてください。分からない言葉があれば、最後にまとめて質問してください。
```

### 2. 毎朝1回で、今日やる3つが決まる

説明: 朝の段取りを考える時間を、読むだけの数分にします。止まっているタスクも Claude の方から挙げてくるので、抜けが減ります。多すぎる提案が出るときは「3つだけ」を強めに書いてください。

```text
/update
今日の段取りを決めたいです。

【お願い】
1. やることリストの中から、今日やるべきものを3つだけ選んでください
2. 3日以上止まっているものがあれば、別に挙げてください
3. 私が決めないと進まないものは「あなたの判断待ち」として分けてください

【出力の形】
・今日の3つ：やること／なぜ今日か（1行）／目安の時間
・止まっているもの：やること／止まっている理由（分かる範囲で）
・あなたの判断待ち：決めてほしいこと（1行）
・全体で10行以内、日本語で
```

### 3. 新しい人や略語を、まとめて覚えさせる

説明: 新しい取引先や案件が増えたときに使います。覚えさせておくと、報告や下書きの中で名前をまちがえにくくなります。覚えた内容がずれていたら、その行だけ直して送り直せばOKです。

```text
覚えてほしい人と言葉が増えたので、記憶に足してください。

【人】
・〔名前〕：〔会社名・役割・私との関係〕
・〔名前〕：〔会社名・役割・私との関係〕

【言葉】
・〔略語やあだ名〕＝〔何のことか〕
・〔略語やあだ名〕＝〔何のことか〕

【お願い】
・すでに覚えている人や言葉と重なるものがあれば、どちらを残すか私に聞いてください
・足し終わったら、今回足したものだけを表で見せてください
・以後、この名前が出てきたら、この内容のとおりに扱ってください
```

### 4. 金曜の10分で、今週の振り返りと来週の段取りを作る

説明: 週の終わりに、終わったこと・持ち越し・来週の優先順位を1枚にまとめます。上司への週報の下書きにもそのまま使えます。数字が要る報告なら、元の資料を添付してから頼んでください。

```text
/update
今週の振り返りと、来週の段取りを作ってください。

【お願い】
1. 今週終わったことを、やることリストから挙げてください
2. 終わらなかったことは、理由と、来週いつやるかを1行で添えてください
3. 来週の優先順位を、上から5つ並べてください

【出力の形】
・「今週終わったこと」「持ち越し」「来週の優先5つ」の3つの見出し
・上司にそのまま送れる、です・ます調の週報の下書きを最後に1つ（200字以内）
・日本語で、事実だけ。分からないことは「未確認」と書く
```

### 5. メールと予定から、やり残しを拾い上げる

説明: メールやカレンダーをつないでいる人向けです。依頼に書いていない所にある約束まで拾うため、Opus 5.5 の公式ガイドがすすめる「先に見て回る」一文を入れています。つないでいない人は、メールの本文を貼ってから使ってください。

```text
/update --comprehensive
やり残しや、返事を忘れている約束がないか確かめてください。

作業を始める前に、つないでいるアプリの中で、関係しそうなメール・予定・チャット・資料を一覧にして開き、見つけたことを使ってください。依頼に書いていないものも含めて探してください。

【お願い】
・私が「送ります」「確認します」と約束したのに、まだ済んでいないものを挙げてください
・相手・約束した内容・期限・見つけた場所（どのメールか）を書いてください
・見つけたものは、やることリストに足す前に私に見せてください

【出力の形】表で、期限が近い順に。日本語で。
```

## Marketing（告知文を書かせる）

### 6. 新商品の告知を、SNS3案とメルマガまで一度に作る

説明: 告知文を白紙から書く時間がなくなります。材料を箇条書きで渡すのがコツで、最後の「守ること」が Opus 5.5 だとそのまま効きます。ありきたりな文になったら、過去の投稿を1つ貼って「この口調で」と足してください。

```text
/draft-content
新商品の告知を作ってください。

【材料】
・商品名：〔　〕
・価格：〔　〕／発売日：〔　〕
・いちばんの特徴：〔　〕
・気をつけてほしい点：〔例：食洗機は使えない〕
・売る場所：〔例：自社サイトと Instagram〕

【ほしいもの】
1. Instagram の投稿文を3案（それぞれ120字以内）
2. メルマガ1本（件名3案と、本文400字）

【守ること】
・日本語の「です・ます」で書く。絵文字は使わない
・「最高」「日本一」のような、言い切れない言葉は使わない
・気をつけてほしい点は、隠さずに入れる
```

### 7. 出す前に、言いすぎ・書き方のずれを点検する

説明: 投稿やチラシを出す前の最終チェックに使います。言い切れない表現や、自社のルールからのずれを、直した文つきで出してくれます。自社のルールがない場合は、下の例の3行だけでも効きます。

```text
/brand-review
次の文を、出す前に点検してください。

【点検する文】
〔ここに投稿文やメルマガを貼る〕

【うちの書き方のルール】
・〔例：です・ます調／1文40字まで／絵文字なし〕
・〔例：「最高」「日本一」など根拠のない言い切りは使わない〕
・〔例：価格は税込で書く〕

【出力の形】
・問題のある箇所を、重さ（高・中・低）の順に表で
・各行に「今の文」「直した文」「理由」
・問題がなければ「このまま出してOK」と一言で
```

### 8. 1か月分の販促の計画を、週ごとの予定表にする

説明: 何をいつ出すかを考える時間を減らします。目標と予算を先に書くと、無理のない計画になります。やることが多すぎたら「1週間に2本まで」のように上限を足してください。

```text
/campaign-plan
来月の販促の計画を作ってください。

【前提】
・売りたいもの：〔商品やサービス〕
・目標：〔例：1か月で30個売る／メルマガ登録を100人増やす〕
・使える場所：〔例：Instagram・メルマガ・自社サイト〕
・使えるお金：〔例：広告費0円〕／使える時間：〔例：週3時間〕

【ほしいもの】
・ねらう人（1行）と、伝えたいこと（1行）
・4週間分の予定表（週ごとに、出すもの・場所・目的）
・うまくいったかを見る数字（2〜3個）

【守ること】日本語で。1週間に出すものは3本まで。
```

### 9. 買ってくれた人へのフォローメールを3通そろえる

説明: 買ったあとのお礼・使い方・次の提案を、送る日まで決めた3通にします。リピートにつながる流れを一度作れば、毎回使い回せます。売り込みが強すぎるときは「3通目だけ提案」と書き足してください。

```text
/email-sequence
商品を買ってくれた人へのフォローメールを3通作ってください。

【前提】
・商品：〔　〕
・買った人が困りやすいこと：〔例：お手入れの方法〕
・次にすすめたい商品：〔　〕

【ほしいもの】
・1通目（買った翌日）：お礼と、届いたら最初にしてほしいこと
・2通目（1週間後）：上手な使い方のコツを1つ
・3通目（1か月後）：次の商品の紹介
・それぞれ、件名2案と本文300字以内

【守ること】日本語の「です・ます」で。絵文字なし。売り込みは3通目だけ。
```

### 10. 競合と比べて、自社の打ち出し方を見つける

説明: 「うちは何を推せばいいか」を、競合との比較から考えます。まだ誰も言っていない切り口が見つかると、告知文が書きやすくなります。調べた数字や出来事は、必ず元のページで確かめてから使ってください。

```text
/competitive-brief
競合と比べて、うちの打ち出し方を考えてください。

【前提】
・うちの商品：〔　〕／価格：〔　〕
・競合：〔会社名や商品名を2〜3個〕
・うちの強みだと思うこと：〔　〕

【ほしいもの】
1. 競合それぞれが推していること（1社1行）
2. どの競合も言っていないが、うちなら言えること（3つ）
3. 次の告知文で使える、ひとこと（キャッチコピー）を3案

【守ること】
・日本語で。調べた内容には、どこで見たかを添える
・分からないことは推測で埋めず「不明」と書く
```

## Data（売上を分析させる）

### 11. 初めて見る表の中身を、最初に点検する

説明: 分析を始める前に、欠けている所・おかしな数字を先に見つけます。あとで数字が合わない、という手戻りが減ります。列の意味がずれて読まれたら、どの列が何かを一言足してください。

```text
/explore-data
添付した表の中身を、分析を始める前に確かめてください。

【お願い】
1. 何行・何列あって、それぞれの列が何を表していそうか
2. 空欄が多い列、同じ行の重なり、ありえない数字（マイナスの個数など）
3. この表で答えられそうな質問を3つ
4. 日付・金額・商品名の書き方がそろっていない列があれば、その例

【出力の形】
・表で、列ごとに「中身」「空欄の割合」「気になる点」
・最後に「分析の前に直したほうがいいこと」を箇条書きで
・日本語で
```

### 12. 売上が落ちている原因を、数字で絞り込む

説明: 「なんとなく売れていない」を、どの商品・どの時期・どの場所かまで絞ります。会議でそのまま話せる結論が1行で出ます。原因が決めきれないときは「確かめるのに要るデータ」を聞き返してください。

```text
/analyze
添付の売上の表で、売上が落ちているものと、その原因の候補を教えてください。

【お願い】
1. 商品ごと・週ごとに売上を並べ、落ちているものを挙げてください
2. いつから落ちたか、どの販売場所で落ちたかも分けて見てください
3. 原因の候補を、表から言えることと、表だけでは言えないことに分けてください

【出力の形】
・最初に結論を1行
・落ちているもの：商品／いつから／前と比べて何%
・原因の候補と、確かめるのに要るデータ
・日本語で
```

### 13. 会議に出すグラフを、1枚で作る

説明: 伝えたいことが一目で分かるグラフを1枚作ります。どのグラフの形がいいかも選んでくれるので、作り直しが減ります。色やラベルが細かすぎたら「文字は大きく、色は2色まで」と足してください。

```text
/create-viz
添付の表から、会議で見せるグラフを1枚作ってください。

【伝えたいこと】
〔例：新商品は発売2週で、主力商品の売上を超えた〕

【お願い】
・伝えたいことがいちばん分かるグラフの形を選んで、理由を1行で書いてください
・タイトルに結論を書いてください
・注目してほしい所に、短い説明を1つ入れてください
・グラフの下に、読み取れることを1行で添えてください

【守ること】日本語のラベル。文字は大きく、色は2色まで。
```

### 14. 毎週見る数字を、ひとつの画面にまとめる

説明: 週報のたびに表を作り直す手間がなくなります。絞り込みができる画面なので、商品別・週別をその場で切り替えて見せられます。見づらいときは「上にいちばん大事な数字を3つ」と足してください。

```text
/build-dashboard
添付の売上の表から、毎週見るための画面を作ってください。

【のせたいもの】
・いちばん上に、今週の合計売上・先週との差・いちばん売れた商品の3つ
・商品ごとの週の売上の推移（グラフ）
・販売場所ごとの割合

【お願い】
・商品と期間で絞り込めるようにしてください
・ブラウザで開くだけで見られる、1つのファイルにしてください

【守ること】日本語のラベル。数字は円で、3けたごとにカンマ。
```

### 15. 分析を人に見せる前に、まちがいを点検する

説明: 集計のまちがいや、言いすぎた結論を、報告の前に見つけます。数字を出す前の安全装置として、毎回の最後に使うのがおすすめです。一覧で「validate」と付くものを選んでください。

```text
/validate
この分析を、上司に見せる前に点検してください。

【点検してほしい分析】
〔ここに分析の結論や表を貼る。または直前の分析をそのまま点検〕

【見てほしいところ】
1. 合計や平均の計算が合っているか
2. 一部だけを見て、全体のことを言っていないか
3. 表から言えないことを、言い切っていないか

【出力の形】
・問題のある箇所を表で（どこ／何が問題か／どう直すか）
・直した結論を1〜2行で
・問題がなければ「このまま出してOK」と一言
```

## Sales（商談をまとめさせる）

### 16. 商談の前に、相手の会社を5分で調べる

説明: 相手の会社の最近の動きと、話すきっかけを先に押さえます。Opus 5.5 は数字や出典のまちがいが前より少ないですが、ゼロではないので、使う数字は元のページで確かめてください。

```text
/account-research
〔会社名〕について、商談の前に調べてください。

【知りたいこと】
1. どんな会社か（事業・規模・拠点）を3行で
2. ここ半年の新しい動き（出店・新商品・採用など）
3. うちの〔商品やサービス〕が役に立ちそうな場面

【守ること】
・日本語で。調べた内容には、どこで見たか（ページ名）を添える
・見つからないことは推測で埋めず「不明」と書く
・最後に、商談の最初に話すと良さそうな話題を2つ
```

### 17. 商談の準備を、聞くことリストまで作る

説明: 何を聞けばいいか分からないまま商談に出ることがなくなります。相手の悩みを引き出す質問が、順番つきで出ます。前回のメモがあれば一緒に貼ると、続きの話から入れます。

```text
/call-prep
〔日時〕に〔会社名〕の〔相手の名前・役職〕と商談します。準備をしてください。

【分かっていること】
〔前回のメモや、今までのやりとりを貼る。なければ「初めての商談」〕

【ほしいもの】
1. この商談のゴール（1行）
2. 聞くことリスト（話す順に7つまで。相手の困りごとを聞く質問を先に）
3. 聞かれそうな質問と、答え方（3つ）
4. 最後に次の約束を取る一言

【守ること】日本語で。1枚に収まる長さで。相手の会社のことは、分かっている範囲だけで書き、推測は「推測」と書く。
```

### 18. 商談メモを、やることとお礼メールに変える

説明: 商談のあとの整理とメール作りが、メモを貼るだけで終わります。期限と担当が並ぶので、約束の抜けも減ります。値段や納期は、必ず自分で確かめてから送ってください。

```text
/call-summary
次の商談メモを整理してください。

【商談メモ】
〔走り書きのメモをそのまま貼る〕

【ほしいもの】
1. まとめ（3行）
2. やること：内容／担当／期限（表で）
3. 相手が気にしていたこと
4. お礼メールの下書き（件名と本文。気にしていたことへの答えを先に書く）
5. 社内のチャットに流す3行の共有メモ

【守ること】
・日本語の「です・ます」で
・メモにない値段や日付は書かず、「〔要確認〕」と残す
・メールは送らず、下書きだけ
```

### 19. 「高い」と言われたときの返し方を用意する

説明: よくある断り文句に、その場で慌てずに返せるようになります。言い返すのではなく、相手の本当の心配を聞き出す流れで出してくれます。自社の実績や数字があれば足すと、説得力が上がります。

```text
/handle-objection
商談で「〔例：ちょっと高いですね〕」と言われました。返し方を考えてください。

【前提】
・うちの商品：〔　〕／価格：〔　〕
・相手：〔例：カフェのオーナー。2店舗〕
・比べられていそうなもの：〔例：量販店のマグカップ〕

【ほしいもの】
1. この言葉の裏にありそうな本当の心配（3つ）
2. それぞれへの返し方（話し言葉で2〜3文）
3. 返したあとに聞く質問（1つずつ）

【守ること】日本語で。値引きはすぐ提案しない。うそや大げさな言い方はしない。
```

### 20. 朝いちばんに、今日の営業の段取りをそろえる

説明: 今日の商談・返事待ち・締め切りが近い案件を、朝の1回でまとめて見られます。メールや予定をつないでいる人は、Opus 5.5 の公式ガイドがすすめる「先に見て回る」一文で、書いていない所の返事待ちまで拾えます。

```text
/daily-briefing
今日の営業の段取りを出してください。

作業を始める前に、つないでいるアプリの中で、関係しそうなメール・予定・メモを一覧にして開き、見つけたことを使ってください。依頼に書いていないものも含めて探してください。

【ほしいもの】
1. 今日の商談：時間／相手／準備しておくこと
2. 返事を待たせている相手：誰に／何を／いつから
3. 今日いちばん大事なこと（1つだけ）

【守ること】
・日本語で、全体で15行以内
・つないでいない情報は「不明」と書く
・メールの送信など、外に出る操作はしない
```
