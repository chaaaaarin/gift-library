# 🎁 Claudeユーザーのための「埋めるべき穴」チェックリスト

自分の毎日の作業を棚おろしして、Claude だけでは埋まらない「音声入力・動画・長時間タスク」の穴がどこにあるかを特定し、その穴に Gemini のどの機能を当てるかまで決めるためのシートです。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 1週間の自分の作業を思い出しながら、上から順に □ を埋めていきます。「→ YES」に当たったものだけ、右側の行動をメモしてください。全部埋める必要はありません。

```text
【Claudeユーザーのための「埋めるべき穴」チェックリスト】

■ ステップ1：音声入力の穴を探す
□ 会議・打ち合わせ・インタビューの内容を、後から文字にして残す作業が週1回以上あるか
  → YES: それは Claude では完結しない。Gemini 3.5 Transcribe（または Whisper 等）を「文字起こし専用」として足す候補
  指示例（試すときの最初の1本）: 直近の会議録音を1本、AI Studio の Gemini 3.5 Transcribe に投入 → 出てきたテキストを Claude に貼って「決定事項とToDoを抜き出して」と頼む
□ 自分がしゃべった内容を、その場で整った文章にしたい場面があるか（口述で下書きを作る等）
  → YES: これは Claude の音声モード／Claude Code の音声入力でも「端末で文字化してテキストを渡す」ところまではできる。まず今の環境で足りるか試す。足りない（整形・フィラー除去まで欲しい）なら Transcribe
□ 手元にある「録音ファイル」を AI に読ませたい場面があるか
  → YES: Claude の API は音声ファイルを受け付けない。ここは確実に Gemini 側（または他の文字起こし）が必要

■ ステップ2：動画の穴を探す
□ SNS・説明用・プロトタイプなど、短い動画を自分で作る（作りたい）場面があるか
  → YES: Claude は画像生成すらしないので、動画は守備範囲の外。Gemini Omni 1.1 Flash か Veo 3.1 を足す候補
  指示例（試すときの最初の1本）: Google Flow で 360p の下書きを2〜3本作り、当たりだけ 1080p / 4K にアップスケールする。1本は40秒が上限なので、10秒×4カットの構成で考える
□ 「安く量を作りたい」のか「1本を作り込みたい」のか
  → 安く量: Veo 3.1 Lite（720p が半額）
  → 作り込み: Omni 1.1 Flash（シーン延長・開始/終了フレーム指定・360p下書きはこちらだけ）
□ 動画を作る予定は当面ないか
  → YES: この穴は今は無視してよい。動画の必要が出てから戻ってくる

■ ステップ3：長時間タスク・毎朝の確認の穴を探す
□ 「毎朝、予定＋重要メールをまとめて確認する」のに5分以上かけているか
  → YES: Gemini Live の Daily Brief（Gmail＋カレンダーを1つの音声ダイジェストに）が候補。Google AI Plus 以上が必要
□ 「数日〜数週間かかる調べ物・資料作成」を、AI に裏で少しずつ進めさせたい場面があるか
  → YES: Gemini Live の Spark が候補。Google AI Pro 以上が必要。Claude には相当機能がない
□ 声でメールの検索・要約・アーカイブ・削除まで任せたいか
  → YES: これは Claude の音声モードでも連携アプリ経由でできる。まず Claude で試し、足りなければ Gemini Live

■ ステップ4：穴を1つに絞る
□ ステップ1〜3で「→ YES」が付いた項目を全部書き出したか
  → YES: その中で「いま一番時間を取られている」ものに丸を付ける。複数同時に手を出さない
□ 丸を付けた穴に、対応する Gemini 機能（または Claude で足りる、の結論）を1つ書いたか
  → YES: それが今週の「足すもの」。無料枠 or 既存プランで試せるものから始める
指示例（1週間後の振り返り）: 「その作業にかけていた時間」を導入前と導入後で数える。減っていなければ元に戻す。増やした機能は1つずつしか評価しない

■ つまずきどころ
・穴が3つ以上見つかった → 全部やろうとしない。時間で一番痛いもの1つだけ
・「Claude で足りるか」が判断できない → まず Claude の音声モードで3日使ってから決める。使わずに Gemini を足すと二重管理になる
・有料プランの課金をためらう → Transcribe は開発者向けに無料枠がある。まずそこで文字起こしだけ試す
・日本で使えるか不安 → Gemini Live の新機能は対象国・言語が公式未発表。文字起こし・動画は AI Studio / Flow から先に触れる
```

**ポイント**: 穴は一度に1つだけ埋めます。2つ以上同時に新しいツールを足すと、どれが効いたのか分からなくなり、結局どれも定着しません。

# 録音した音声を、整った文章にして書き出すまでの手順・設定・そのまま貼れるプロンプトを1枚にまとめたキットです。受け取ったその日に、手元の音源で1本試せます。

# 🎁 会議・インタビュー文字起こし 発注キット（Gemini 3.5 Transcribe / AI Studio 版）

録音した音声を、整った文章にして書き出すまでの手順・設定・そのまま貼れるプロンプトを1枚にまとめたキットです。受け取ったその日に、手元の音源で1本試せます。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: Google AI Studio（aistudio.google.com）を開き、下の手順に沿って進めます。ステップ4の整形プロンプトは、文字起こし結果に対してそのまま貼って使います。

```text
【会議・インタビュー文字起こし 発注キット / Gemini 3.5 Transcribe・AI Studio版】

■ ステップ1：どの条件で文字起こしするかを先に決める
□ 音源は「録音済みファイル」か「これから録音しながら」か
  → YES 録音済み: 非ストリーミング（gemini-3.5-transcribe）を選ぶ。誤り率が低く、後から整形しやすい
  → YES 録音しながら: ストリーミング（gemini-3.5-transcribe-live）を選ぶ。1セッション最大10分なので、長い会議は10分ごとに区切る
□ 話者を分けて記録したいか（誰が何を言ったか）
  → YES: 話者分離をON。ただし正確に分けられるのは最大3人まで。4人以上の会議は「話者分離OFF＋後から手で名前を振る」方が崩れにくい
□ 音源の長さは
  → 30分以内: そのまま投入できる（話者分離・タイムスタンプ有効時は最大30分、無効なら最大1時間）
  → それ以上: 30分単位でファイルを分割してから投入する
（補足：この条件出しを飛ばすと、途中で切れる・話者がぐちゃぐちゃになる、の2大失敗が起きます）

■ ステップ2：カスタム語彙を登録する（固有名詞の取りこぼしを防ぐ）
□ この音源に出てくる「一般には通じない言葉」を洗い出したか
  → YES: 会社名・製品名・型番・社内の略称・人名を10〜30語ほどリスト化し、AI Studio のカスタム語彙欄に1語ずつ登録する
指示例（カスタム語彙に入れる語の例）:
  Claude Code / Anthropic / MCP / Opus 5 / 田端（たばた） / 案件A-2024 / リリース v3.7 / ワークスペース
□ 英数字の並び（注文番号・電話番号・日付）が多い音源か
  → YES: それらの代表例も2〜3件カスタム語彙に入れておく。Transcribe は英数字の並びを拾うのが得意だが、フォーマットのクセ（ハイフン有無など）は事前に見せた方が揃う

■ ステップ3：投入して、生の文字起こしを受け取る
□ 音源をアップロードし、ステップ1で決めた条件で実行したか
  → YES: フィラー（「えーと」「あの」）は自動で除去され、「火曜——いや水曜」のような言い直しも直された状態で返ってくる
  → 返ってきたテキストは、まだ「話し言葉のかたまり」。ここから下の整形プロンプトで読める形にする

■ ステップ4：整形プロンプト（文字起こし結果に対してそのまま貼る）
指示文:
  以下は会議の文字起こしです。次のルールで清書してください。
  1. 内容は変えず、口語を書き言葉に直す（「〜っすね」→「〜ですね」等）。要約はしない
  2. 話題の切れ目で見出し（##）を付け、話題ごとに段落を分ける
  3. 決定事項・宿題（ToDo）・保留事項の3つを、本文の後に箇条書きで抜き出す。ToDo には「担当者（分かれば）」と「期限（言及があれば）」を付ける
  4. 固有名詞・数字・日付は文字起こしのまま残す。推測で補完しない。聞き取れていない箇所は［不明］と明記する
  出力は「清書本文 → 決定事項 → ToDo → 保留事項」の順で。
（貼り付ける文字起こし本文はこの下に続けて置く）

■ ステップ5：出力を検品する（ここを省くと事故る）
□ 固有名詞・金額・日付を、元音源の該当箇所と1つずつ突き合わせたか
  → NO: 必ず突き合わせる。整形AIは自然な文章を優先するため、数字や社名を「それらしく」書き換えることがある
□ ［不明］が残っている箇所はあるか
  → YES: その部分だけ元音源を聞き直して手で埋める。全体を聞き直す必要はない
□ ToDo に期限・担当が入っているか
  → NO: 会議中に言及がなければ空欄のままでよい。ただし「後で誰かに割り当てる」前提のメモとして残す

■ つまずきどころ
・話者がずれる → 話者分離をOFFにして、後から「Aさん：」を手で振る方が速いことが多い
・専門用語がカタカナで崩れる → ステップ2のカスタム語彙に戻して語を追加し、もう一度実行する
・長い音源で後半が欠ける → 30分（話者分離時）を超えている。ファイルを分割する
・日本語の精度が想定より低い → 公式は日本語単独の数値を公表していない。自分の音源での体感を基準に、他の文字起こし（Whisper 等）とも1本ずつ比べて選ぶ
```

**ポイント**: 整形AIは「読みやすさ」を優先して数字や固有名詞を書き換えることがあります。ステップ5の突き合わせだけは、どんなに急いでいても省かないでください。
