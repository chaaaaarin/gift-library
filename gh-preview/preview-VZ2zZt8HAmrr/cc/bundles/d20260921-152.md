# 🎁 【今スグ使える】トークン100％節約mdファイル

Codex が作業の前に必ず読むルールファイル（AGENTS.md）に置くだけで、頼んでいないサブエージェント・余計なファイルの読み込み・長い前置きや実況に、トークンを使わせない約束ごとが毎回の作業に効きます。設定ファイルを触らずに今日から使え、ルール自体も20行ほどに絞ってあるので、ファイルそのものが読み込みを増やしません。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**:
1. 下のコードブロックをコピーする
2. 全部の作業に効かせたいなら `~/.codex/AGENTS.md`、特定のプロジェクトだけなら、そのプロジェクトのいちばん上のフォルダに `AGENTS.md` という名前で保存する（すでに AGENTS.md がある場合は、末尾に貼り足す）
3. Codex を開き直す（AGENTS.md は Codex を起動したときに読み込まれます）

```text
# トークン節約ルール（作業の前に必ず読む）

■ サブエージェント
- 私が「並列で」「◯体に分けて」と書いたときだけ使う
- 使うときは、先に「何体・どのモデル・何を返すか」を宣言する
- 子には途中経過を返させず、結果の要約だけを返させる

■ 読み込み
- 指定されたファイルと、作業に直接要るファイルだけ読む
- フォルダ全体・過去ログ・大きなファイルは、開く前に確認をとる
- 同じファイルを何度も読み直さない

■ 書き出し
- 前置き・感想・実況は書かない。完成物と確認点だけ書く
- 長さの指定がなければ、短い方を選ぶ
- 直すときは、変えた箇所だけ示す（全体を貼り直さない）

■ 進め方
- 始める前に手順を3行で示す。10ファイル以上触るなら OK を待つ
- 分からない点は推測で進めず、1回にまとめて聞く
- 同じ失敗が2回続いたら止まり、原因と次の案を報告する

■ ツール
- 作業に関係しない MCP のツールは使わない
- テストやコマンドの出力は、失敗した部分だけ要約して伝える
```

**サブエージェントを確実に止めたいとき**: 上のルールは Codex への「お願い」です。並列の作業をまったく使わないなら、設定ファイル `~/.codex/config.toml` にも次の2行を足すと、仕組みごと止まります（編集前にバックアップを取ってください）。

```text
[features]
multi_agent = false

[agents]
enabled = false
```

**ポイント**: AGENTS.md は、いまいるフォルダに近いものほど後から読まれて優先されます。プロジェクト側にも AGENTS.md がある場合は、書いてあるルールと食い違っていないか一度見比べてください。並列で進めたい大きな作業の日は、依頼文に「2体に分けて」のように書けば、このルールのままサブエージェントを使えます。
