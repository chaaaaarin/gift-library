001初回セットアップ
初回セットアップ
前提: まだEmDashサイトを1つも作ったことがない、Cloudflareアカウントは作成済みの状態。
指示: npm create emdash@latestでプロジェクトを初期化し、Cloudflareダッシュボードの「Deploy to Cloudflare」ボタンでデプロイまで一気通貫で進めて。
出力形式: 各ステップで何が起きたかを1行ずつ報告し、最後に公開URLを提示する形式で。
002テーマ選定
テーマ選定
前提: ブログ・マーケティング・ポートフォリオ・ブランクの4種類の公式テンプレートがある状態で、どれを選ぶか決めかねている。
指示: 私の用途（個人の技術ブログ）を伝えるので、最も適したテンプレートを1つ提案し、選ばなかった理由も含めて。
出力形式: テンプレート名・選定理由・カスタマイズすべき箇所を箇条書き3点で。
003記事投稿ワークフロー
記事投稿ワークフロー
前提: 毎週1本、下書きのMarkdownファイルを用意してから公開する運用にしたい。
指示: 下書きフォルダから記事を読み込み、EmDashの記事スキーマに合わせて整形し、公開前のプレビューまで作って。
出力形式: 変換前後の差分と、公開前チェック項目のリストを添えて。
004会員限定コンテンツ
会員限定コンテンツ
前提: 無料記事と有料記事を混在させたいが、まだD1のスキーマを設計していない。
指示: 会員フラグを持つ記事スキーマをD1に設計し、未ログインユーザーには冒頭だけ表示するロジックを実装して。
出力形式: スキーマ定義（SQL）と、表示制御のコード差分を分けて提示する形式で。
005問い合わせフォーム
問い合わせフォーム
前提: サイトに問い合わせフォームがなく、メールソフトへの直接連絡だけになっている。
指示: D1にお問い合わせを保存し、送信完了時に管理者へ通知が飛ぶフォームを作って。
出力形式: フォーム項目一覧・保存先テーブル定義・通知の飛ばし方を3段落で。
006SEO設定
SEO設定
前提: 記事は書けているが、タイトルタグや構造化データの設定に手が回っていない。
指示: 全記事にmeta description・OGP画像・構造化データ（Article型）を自動生成する仕組みを作って。
出力形式: 既存記事のうち何件が未設定だったかを先に集計してから着手する形式で。
007画像最適化
画像最適化
前提: 記事に貼る画像がそのままの解像度でR2にアップロードされ、表示が重い。
指示: アップロード時に自動でリサイズ・WebP変換してからR2に保存する処理を組み込んで。
出力形式: 変換前後のファイルサイズ比較を1件サンプルで示す形式で。
008多言語対応
多言語対応
前提: 日本語記事しかないが、将来は英語版も出したいと考えている。
指示: 記事スキーマに言語フィールドを追加し、言語別のURL構造（/ja/ /en/）を設計して。
出力形式: URL設計案とスキーマ変更案を、移行の要不要も添えて提示する形式で。
009RSS配信
RSS配信
前提: 読者からRSSで購読したいという要望が来ている。
指示: 全公開記事を対象にしたRSSフィードをWorkers上で動的生成する仕組みを作って。
出力形式: 生成されるXMLのサンプルを1件分だけ添えて。
010コメント機能
コメント機能
前提: 記事へのコメント欄がなく、読者との対話ができていない。
指示: D1にコメントを保存し、投稿前にスパム的な内容を簡易フィルタする機能を追加して。
出力形式: フィルタの判定基準を箇条書きで、承認フローの有無も明記する形式で。
011検索機能
検索機能

出力形式: 検索速度の目安と、対応できない検索パターン（あいまい検索等）を注記する形式で。
012サイトマップ

出力形式: 生成URLの件数と、更新頻度の設計方針を1段落で。

指示: Cloudflare Web Analyticsを導入し、記事ごとのPV数を管理画面から確認できるようにして。
出力形式: 導入手順を3ステップ、計測開始までの所要時間の見込みも添えて。
014ニュースレター連携

出力形式: トリガーの発火条件と、配信メール本文のテンプレート案を提示する形式で。
015ポートフォリオ型サイト
ポートフォリオ型サイト
前提: ブログ用途ではなく、制作物を並べるポートフォリオとして使いたい。
指示: プロジェクト単位のスキーマ（サムネイル・概要・使用技術・リンク）を設計し、一覧・詳細ページを作って。
出力形式: スキーマ定義と、一覧ページのレイアウト方針を分けて提示する形式で。
016EC的な使い方
EC的な使い方
前提: 商品を数点だけ紹介し、購入は外部リンクに誘導する簡易ECにしたい。
指示: 商品スキーマ（価格・在庫・外部購入リンク）を設計し、一覧・詳細ページを作って。
出力形式: 在庫切れ時の表示分岐も含めた仕様を1段落で。
017予約フォーム
予約フォーム
前提: 個人事業として、面談・レッスンの予約をサイト経由で受け付けたい。
指示: 空き枠をD1で管理し、埋まっている枠は選択できない予約フォームを作って。
出力形式: 予約データのテーブル構造と、二重予約防止のロジックを説明する形式で。
018FAQページ自動生成
FAQページ自動生成
前提: 問い合わせで同じ質問が繰り返し来ており、FAQページを整備したい。
指示: 過去の問い合わせ履歴（テキストで渡す）から頻出質問を抽出し、FAQページ用のQ&Aを生成して。
