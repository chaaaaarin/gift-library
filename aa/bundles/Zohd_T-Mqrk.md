# 🎁 新モデル発表「鵜呑み防止」チェックリスト

次に「新AIモデルが〇〇を超えた」というニュースを見た時に、見出しを鵜呑みにせず内容を正しく理解するための判断シートです。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 気になる新モデル発表のニュースを読む前・読みながら、上から順に確認してください。

```text
【新モデル発表 鵜呑み防止チェックリスト】

■ ステップ1：見出しの主語を確認する
□ 「〇〇がGPT-5.6/△△を超えた」の主語は誰の発表か？
  → YES(自社発表): 独立した第三者ベンチマークの裏付けがあるか探す
  → YES(第三者ベンチマーク): どの指標での比較かを次に確認する
指示例: この発表内容が自社発表か第三者ベンチマークか教えて。

■ ステップ2：指標が「特定タスク」か「総合力」かを見分ける
□ 見出しの根拠になっている数値は、コード生成など個別ベンチマークか？
  → YES: 「その分野では」という限定つきで理解する
□ Intelligence Index・GDPval等の総合指標か？
  → YES: 総合力の話として理解してよい
指示例: この比較は個別ベンチマークか総合指標か整理して。

■ ステップ3：価格表記がlist priceかblended(実効)価格かを区別する
□ 「〇〇より安い」という主張の価格は、公式のlist price(入力/出力別)か？
□ それとも比較サイトのblended price(タスク単価の平均値)か？
  → 両方確認し、同じ土俵で比較されているか確かめる
指示例: この価格比較はlist priceかblended priceか教えて。

■ ステップ4：パラメータ数・スペック表記の幅を確認する
□ 「〇兆パラメータ」等の数字が、報道によって微妙に異なっていないか？
  → YES: フルウェイト公開や公式技術レポート等、確定情報が出るまで幅を持たせて理解する

■ ステップ5：株価・市場の反応と実力を切り分ける
□ 「株価が動いた」「時価総額が逆転した」という情報が実力の証明として扱われていないか？
  → YES: 市場の反応は「驚きの大きさ」の指標であり、性能の証明ではないと理解する

■ ステップ6：独立検証者の声を探す
□ 自社発表・提携メディア以外の第三者(個人開発者・YouTuber等)による実測レビューがあるか？
  → YES: そちらを優先して判断材料にする
  → NO: 独立検証が出るまで判断を保留する
指示例: この新モデルについて独立した第三者による実測レビューを探して。

■ ステップ7：結論を一文でまとめる
□ 「◯◯は△△より、[具体的な指標]で上回るが、[別の指標]では及ばない」という
  形で自分の言葉に落とし込めるか？
  → YES: このニュースを正しく理解できている
  → NO: ステップ1に戻って再確認する
```

**ポイント**: 「超えた」という見出しの9割は、特定の指標・特定条件下での話です。総合力の話なのか個別指標の話なのかを最初に切り分けるだけで、判断の精度が大きく変わります。
