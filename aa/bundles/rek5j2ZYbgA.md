# 🎁 導入前セキュリティ&権限チェックリスト

Workspace Studioを社内で使い始める前に確認しておきたいことを、5ステップのチェックリストにまとめました。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 導入担当者・情報システム部門との確認作業にそのまま貼って使ってください。

```text
【導入前セキュリティ&権限チェックリスト】

■ ステップ1: 利用条件を満たしているか
□ 会社・組織のGoogle Workspace有料アカウントを使っているか(個人のgmail.comでは利用不可)
→ YES: ステップ1-2へ
指示例: 管理者に「うちのWorkspaceプランでWorkspace Studioは使えますか」と確認する

□ 管理コンソールの「生成AIの設定」→「Gemini for Workspace」で、Workspace Studioがオンになっているか
→ YES: ステップ2へ　→ NO: 管理者にオン化を依頼する

■ ステップ2: 情報ソースの設定を確認する
□ フローの中でGeminiに渡す情報ソースが「Workspace内の情報のみ」か「Web検索も含む」か、フローごとに意図して選んでいるか
→ YES: 機密情報を扱うフローは「Workspaceのみ」に絞る
指示例: 「このフローのGeminiの情報ソースは、Workspace内の情報だけに限定してください」

■ ステップ3: 出力の安定性を担保する
□ Geminiに複雑な判定をさせるとき、JSON形式で出力させているか
→ YES: 後段の条件分岐が安定しやすい
指示例: 「返信要否・要約・返信案の3つの値を持つJSONスキーマで回答してください」

□ JSON出力の直後に「抽出ステップ」で値を取り出しているか
→ YES: 次のステップ以降が扱いやすくなる

■ ステップ4: 上限・実行回数を把握する
□ 作成できるフロー数(最大25個)・1フローの最大ステップ数(20)を把握しているか
→ YES: 設計時に余裕を見て組む

□ 月間の実行回数上限(2026年9月1日から適用開始予定)を確認したか
→ YES: 本格運用の前にプラン変更の要否を検討しておく

■ ステップ5: 外部連携の実態を確認する
□ Salesforce・Jira・Mailchimp等の外部連携を前提にしていないか(2026年6月時点で利用できないという報告がある)
→ YES: 自社環境で実際に接続できるかを事前に確認する
指示例: 「まずテスト用のフローで、実際に外部連携ステップが使えるか確認してください」
```

**ポイント**: 特にステップ5は公式サイトの説明と実際の挙動にズレがある可能性があるため、本番導入前に必ず自社環境で実機確認してください。
