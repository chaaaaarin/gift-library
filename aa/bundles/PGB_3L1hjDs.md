# 🎁 ハンズフリー活用チェックリスト

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 手が離せない場面に遭遇したら、このシートで判定してから話しかけてください。

```text
【ハンズフリー活用チェックリスト】

■ ステップ1：今、手や目がどれくらいふさがっているか確認する
□ 両手が完全にふさがっている（運転・料理・育児中など）
□ 片手は空いているが画面は見られない（満員電車など）
□ 手は空いているが画面を見たくない（就寝前など）
→ YES: いずれか1つでも当てはまれば、GPT-Liveの音声利用に向いている場面

■ ステップ2：周囲の環境を確認する
□ 声を出しても迷惑にならない場所にいる
□ 会話の内容を他人に聞かれても問題ない
□ 極端な騒音の中ではない（新幹線の車内アナウンス直下等は避ける）
→ YES: 全て満たしていれば音声で話しかけて問題なし
→ NO: 「静かに聞いていてください」と伝えて片方向の利用に切り替える

■ ステップ3：やりたいことが画面・映像を必要とするか確認する
□ 画面共有や動画を見せる必要がある
□ 資料をその場で目視確認したい
→ YES: この場合はGPT-Liveでは対応できない（リリース時点で非対応）。従来の音声モードかテキストChatに切り替える
→ NO: そのままGPT-Liveで進めてよい

■ ステップ4：割り込みや中断が発生しそうか確認する
□ 途中で誰かに話しかけられる可能性が高い（育児中・接客中等）
□ 移動中で電波状況が不安定になりそうな区間がある
→ YES: 「中断したら『続き』と言うので、そこから再開して」と最初に伝えておく
→ NO: 通常通り話しかけて問題ない

■ ステップ5：会話の内容が機密情報を含むか確認する
□ 個人情報・パスワード・社外秘の情報を話す予定がある
□ 周囲に人がいて会話が聞こえる環境である
→ YES: 音声での利用は避け、静かな場所に移動するかテキスト入力に切り替える
→ NO: そのまま音声で進めてよい

■ ステップ6：どのReasoning Effortを使うか最終確認する
□ 急いでいる／テンポ重視 → Instant
□ 少し考えてほしい相談ごと → Medium
□ 調べ物や複雑な判断が必要 → High
→ YES: 該当するレベルに設定してから話しかける
```

**ポイント**: ステップ3・5で「NO以外」に該当した場合は無理に音声を使わず、他の方法に切り替えるのが安全です。

# 🎁 Reasoning Effort使い分け早見表

□ 単純な計算や暗記の一問一答

■ ステップ2：多少考えて、整理された答えが欲しいか？
□ 予定の整理・要約をしてほしい
□ 簡単な相談・壁打ち相手になってほしい
□ 語学練習や面接練習の相手役をしてほしい
→ YES: Mediumに設定する
指示例: 「少し考えてから、整理して答えてほしい」

■ ステップ3：Web検索や複雑な計算・専門的な調べ物が必要か？
□ 最新のニュースや情報を調べてから答えてほしい
□ 込み入った意思決定の相談をしたい
□ 複数の条件を踏まえた比較・分析をしてほしい
→ YES: Highに設定する
指示例: 「じっくり調べて、根拠つきで答えてほしい」

■ ステップ4：設定を切り替える手順
□ ChatGPTアプリを開く
□ 設定 → 音声 → Intelligence の順に進む
□ Instant／Medium／Highから選んで保存
→ YES: 切り替え完了後、音声ボタンを押してすぐに反映を確認する

■ ステップ5：迷ったときの判断基準
□ 「待たされてもいいから正確な答えが欲しい」ならHighへ
□ 「多少ざっくりでもいいからテンポ重視」ならInstantへ
□ 判断に迷う場合はMediumを基本設定にしておく
→ YES: まずMediumで様子を見て、物足りなければHighへ調整する

**ポイント**: レベルを上げるほど応答までの待ち時間も伸びます。急いでいる場面ではInstant寄りに倒すのがおすすめです。
