# 🎁 Open Design 導入コマンド早見表

【Open Design 導入コマンド早見表】

■ デスクトップアプリ(推奨・GUI操作のみ)

### 3. ツール選び判定シート(Claude Design / Figma / Open Design)（テンプレート）
# 3つのツールのうちどれを使うべきか、4ステップで判定できるチェックシートです。

# 🎁 ツール選び判定シート(Claude Design / Figma / Open Design)

3つのツールのうちどれを使うべきか、4ステップで判定できるチェックシートです。

**受け取り方**: 下のコードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 上から順に自分の状況にチェックを入れ、最後の「最終確認」で結論を出してください。

```text
【Claude Design / Figma / Open Design 判定シート】

■ ステップ1:予算はどちらか
□ 追加費用をかけたくない・チームで無料配布したい → YES: Open Designへ
□ 既にClaude Pro/Max/Team/Enterpriseを契約済みで追加操作が要らない方がいい → YES: Claude Designへ

■ ステップ2:誰が作業するか
□ ピクセル単位の細かい調整をデザイナーが行う → YES: Figmaへ
□ AIエージェントに任せて初稿を素早く量産したい → YES: Open DesignまたはClaude Designへ

■ ステップ3:使っているAIエージェントは何か
□ Claude Codeだけを使っている → YES: Claude DesignかOpen Designどちらでも可(無料重視ならOpen Design)
□ Codex・Cursor・Gemini CLI等、Claude以外もよく使う → YES: Open Designへ(Claude Designは非対応)

■ ステップ4:成果物の置き場所
□ 自社サーバー・ローカルにデータを置きたい(セルフホスト必須) → YES: Open Designへ
□ クラウド完結で構わない → YES: Claude DesignかOpen Design Cloudのどちらでも可

■ 最終確認
□ 上記で2つ以上「Open Design」に丸がついた → YES: まずOpen Designを試す
□ 上記で2つ以上「Claude Design」または「Figma」に丸がついた → YES: そちらを優先し、必要に応じてOpen Designを併用
```

**ポイント**: 3つは競合ではなく用途違いです。まずは無料のOpen Designを試してから、必要に応じて他ツールと併用するのがおすすめです。
