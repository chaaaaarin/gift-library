# 🎁 資料もサムネも“外注ゼロ”で仕上がる Astra画像生成プロンプト10選

デザイナーに頼んでいたサムネ・アイキャッチ・図解・モックアップを、Astraにそのまま貼るだけで下地が出せる10本です。1枚あたり30〜60分かかっていた素材づくりが5分になり、しかも回を追うごとにトーンが揃います。仕事で本当に使う用途だけに絞ってあります。

**受け取り方**: 下の各コードブロック右上のコピーボタンでコピーするか、このファイルをそのままダウンロードしてください。

**使い方**: 1〜3はSNS・記事の集客用、4〜6は資料・スライド用、7〜10はサービス/商品まわり。プロンプト末尾の「16:9」「1:1」などの比率と、色・除外条件だけ自分の案件に置き換えれば動きます。

---

## 1. クリックされるYouTubeサムネイルの下地

```text
期待できるメリット: サムネのテンプレ探し・外注に使っていた30〜60分が5分になる。毎回同じ色設計で出るのでチャンネルの見た目が揃う。
使う場面: 動画を出す直前、タイトルは決まっているがサムネ画像がまだないとき。
そのまま貼るプロンプト:
（Astraへ）YouTubeサムネイル用の画像を16:9・1280×720で作ってください。中央やや左に日本人男性の上半身、驚いた表情で口を開き、右手を軽く上げている。背景は暗いネイビーからシアンへのグラデーションに光の放射。画面の右3分の1はあとで文字を載せるので、ほぼ無地で暗く空けておく。被写体は青とシアンのリムライトで縁取り、赤は使わない。実写風だが彩度・コントラストは強め。画像内に文字・ロゴは一切入れない。
調整のコツ: 表情は「驚き／自信／困惑」の3パターンで出して当たりを選ぶ。人物を反対側に置きたいときは「右3分の1を空ける」を「左3分の1を空ける」に変える。
つまずきどころ: 文字まで描かせると崩れる。テキストは必ず後から編集ソフトで載せる。「無地で空ける」を書き忘れると全面に絵が入り、タイトルを置く余白がなくなる。
```

## 2. 記事・ブログのアイキャッチ（抽象コンセプト系）

```text
期待できるメリット: 写真素材サイトを探す時間がゼロになり、記事の内容に正確に合ったビジュアルが毎回手に入る。他サイトと絵がかぶらない。
使う場面: ブログ記事やnote、オウンドメディアの記事を公開する前、本文と合うアイキャッチが見つからないとき。
そのまま貼るプロンプト:
（Astraへ）記事のアイキャッチ画像を16:9で作ってください。テーマは「（例：情報が多すぎて選べない状態から、優先順位が付いて動き出すまで）」。人物や具体的な物は描かず、幾何学的な形と線だけで表現する。左半分は形がバラバラで混沌、右へ進むほど整列していく構図。配色は白背景に濃紺・水色・薄いグレーの3色のみ。フラットで平面的、影は最小限。テキストは入れない。余白は広めに取る。
調整のコツ: 「左は混沌→右は整列」の部分を記事の主張に合わせて書き換える（例：重い→軽い、閉じている→開いている）。3色を自社のブランドカラーに差し替えるとサイト全体で統一できる。
つまずきどころ: テーマを1語（例：効率化）だけで渡すとありきたりな絵になる。「どの状態からどの状態へ」の変化で書くと記事に固有の絵になる。
```

## 3. SNS広告・LP用の“お客様の声”ダミー人物

```text
期待できるメリット: 実在の顧客写真を使わずに、レビュー・導入事例の吹き出しに添える顔写真が用意できる。肖像権・掲載許諾のやり取りが不要になる。
使う場面: LPやSNS広告で「30代・営業職・Aさん」のような架空ペルソナのコメントを載せるとき。
そのまま貼るプロンプト:
（Astraへ）証言コメントに添える人物写真を1:1で作ってください。30代後半の日本人男性、営業職、清潔感のあるシャツ姿。自然な微笑みで正面やや斜めを向き、明るいオフィスを背景に軽くぼかす。証明写真的にならないよう、肩から上のスナップ風。実写風で加工感は控えめ、肌の質感は自然に。特定の有名人に似せない。ロゴ・社名・文字は写り込ませない。
調整のコツ: 年代・性別・職種・服装を変えて4〜6人ぶん出し、ペルソナ表とセットで管理する。背景を「白壁」に変えると切り抜きやすい。
つまずきどころ: 「実在しそうなリアルさ」を上げすぎると誰かに似てしまうことがある。似た顔が出たら作り直す。事例が実話でない場合は「※イメージです」の注記を必ず併記する。
```

## 4. スライド資料用の統一トーンなアイコン風イラスト

```text
期待できるメリット: スライド全体でバラバラだったアイコンやイラストが1つの画風で揃い、資料の完成度が一段上がる。素材集を横断して探す手間が消える。
使う場面: 提案書・社内資料を作っていて、章扉や箇条書きの横に置く小さな挿絵が必要なとき。
そのまま貼るプロンプト:
（Astraへ）スライド資料用のイラストを1:1・透過背景で作ってください。モチーフは「（例：チームで1つの目標を見ている場面）」。線画＋2色塗り（濃紺と山吹色）のフラットスタイル、線は均一な太さ、影・グラデーションなし。人物は頭身を低めにデフォルメ。余白を広めに取り、単体でも箇条書き横でも使えるサイズ感。文字は入れない。
調整のコツ: 最初の1枚が気に入ったら「同じ画風・同じ2色で、次はこのモチーフ」と続けて頼むとシリーズで揃う。モチーフ名だけ変えていくのがコツ。
つまずきどころ: 途中で「もっと写実的に」などと画風の指示を混ぜると揃わなくなる。画風の文（線画＋2色塗り〜影なし）は毎回一字一句そのまま貼る。
```

## 5. プレゼンの章区切り・背景画像

```text
期待できるメリット: セクションの切り替わりが視覚的に分かる資料になり、聞き手が話の構造を追いやすくなる。テンプレート販売サイトを探さなくて済む。
使う場面: 30枚以上のプレゼンで、大きな章の頭に全画面の扉ページを入れたいとき。
そのまま貼るプロンプト:
（Astraへ）プレゼンの章扉用の背景画像を16:9で作ってください。左下から右上へ緩やかに流れる曲線のグラデーション、色は濃紺→藍→わずかに紫。画面の左上4割はタイトル文字を載せるため暗く静かに保つ。質感はマットで、粒状ノイズを弱く乗せる。ロゴや文字、具体的な物体は描かない。落ち着いた高級感、派手なエフェクトは避ける。
調整のコツ: 章ごとに色相だけ少しずつ回す（藍→深緑→ワイン）と、扉を見ただけで「何章か」が分かる。本文スライドは白背景のままにして、扉だけこの濃い背景にすると対比が効く。
つまずきどころ: 文字を載せる位置を指定しないと中央に模様が集中してタイトルが埋もれる。「どの範囲を暗く空けるか」を必ず書く。
```

## 6. 仕組み・フローを説明する図解の下絵

```text
期待できるメリット: 手順やシステム構成を口頭で説明していたものが、1枚の図になって伝わる。作図ツールでゼロから箱を並べる作業を省ける。
使う場面: 業務フロー・データの流れ・体制図などを資料に入れたいが、清書された図がないとき。
そのまま貼るプロンプト:
（Astraへ）業務フローの説明図を16:9で作ってください。左から右へ4つの工程が矢印でつながる横型の流れ図。各工程は角丸の箱で表し、箱の中は空にしておく（あとで自分で文字を入れる）。上下に補助的な小さい箱を1〜2個、点線でつなぐ。配色は白背景＋濃紺の線＋1工程だけ山吹色で強調。手描き感のある均一な線、立体感や影は付けない。装飾は最小限。
調整のコツ: 箱の数・強調する箱の位置を案件に合わせて指定する。「箱の中は空」と書くことで、日本語テキストの描画崩れを避けつつレイアウトだけ借りられる。
つまずきどころ: 箱に文字を入れさせると誤字や意味不明な文字列になる。文字は必ず後入れ。工程が5つ以上なら「2段組みで」と指定しないと窮屈になる。
```

## 8. 手描き風の説明イラスト（親しみを出したいとき）

```text
期待できるメリット: かたい資料や研修テキストに温度が出て、読み手の心理的なハードルが下がる。イラストレーターへの発注コストとリードタイムがなくなる。
使う場面: 社内マニュアル・新人向け資料・セミナー投影など、堅すぎない見た目にしたいとき。
そのまま貼るプロンプト:
（Astraへ）手描き風の説明イラストを4:3・白背景で作ってください。場面は「（例：先輩が新人に付箋を使ったタスク整理を教えている）」。色鉛筆かマーカーで描いたようなラフな線、塗りムラを少し残す。色数は3〜4色に抑え、彩度は低め。人物は表情ゆたかに、頭身低め。背景は描き込みすぎず要点だけ。フキダシや文字は入れない。ほのぼのした雰囲気。
調整のコツ: 場面の説明を「誰が・誰に・何をしている」で具体的に書くほど狙いどおりになる。シリーズ化するなら「同じタッチ・同じ登場人物で、次の場面は〜」と続ける。
つまずきどころ: 「手描き風」だけだと写実寄りに出ることがある。「色鉛筆／マーカー」「塗りムラを残す」まで書くと安定する。
```

## 9. Before / After の比較ビジュアル

```text
期待できるメリット: 改善効果や導入前後の違いが一目で伝わる。左右2枚を別々に作って並べる手間が、1回の指示で済む。
使う場面: 提案資料やSNS投稿で「散らかった状態」→「整った状態」のような変化を見せたいとき。
そのまま貼るプロンプト:
（Astraへ）Before/Afterの比較画像を16:9・左右2分割で作ってください。テーマは「（例：情報が散乱したデスク周り → 整理されて集中できる状態）」。左（Before）は雑然と物が多く、色みも濁って暗い。右（After）は物が減って整然、明るく余白がある。中央に細い区切り線。両方とも同じ画角・同じ机で、状態だけが違う。上部に「Before」「After」を置くスペースを空けておく（文字は描かない）。フラットで見やすいイラスト調。
調整のコツ: 「同じ画角・同じ机で状態だけ違う」を必ず入れる。これがないと別物の絵が2枚並んで比較にならない。
つまずきどころ: 差を強調しようとしてAfterを豪華にしすぎると嘘っぽくなる。「物が減る・明るくなる」程度の現実的な変化にとどめる。
```

## 10. サービスの世界観を伝えるコンセプトアート

```text
期待できるメリット: ブランドの方向性を言葉で説明する代わりに1枚で共有できる。デザイン発注やチーム合意の“たたき台”が数分で用意できる。
使う場面: 新規事業の企画初期、デザイナーや経営陣に「こういう空気感でいきたい」を見せたいとき。
そのまま貼るプロンプト:
（Astraへ）サービスの世界観を表すコンセプトアートを16:9で作ってください。イメージは「（例：夜明けの静かな街で、人々が無理なく朝の準備を始めている）」。全体は落ち着いた寒色に、朝日のオレンジをワンポイント。人物は小さめに複数配置し、生活感を出す。画風は淡い水彩＋うっすらした線画、写実にはしない。細部より空気感と光を優先。ロゴ・文字は入れない。横長で余白のある構図。
調整のコツ: 「時間帯・場所・人が何をしているか・支配的な色・差し色」の5点を毎回指定すると、方向性のブレない絵が続けて出せる。3枚出して1枚を選ぶ前提で。
つまずきどころ: 抽象的な形容詞（先進的、洗練された）だけだと毎回違う絵になる。必ず具体的な場面に翻訳してから渡す。
```

**ポイント**: 画像内の日本語テキストは崩れやすいので、文字はすべて後から編集ソフトで載せる前提にしてください。人物写真を証言・事例に使う場合は、実話でなければ「※イメージです」を必ず併記してください。
