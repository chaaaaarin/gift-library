下のカードから、1件ずつコピー、または個別にダウンロードできます。まとめて欲しいときは、上の「全件ダウンロード」をお使いください。
001ステップ1：Computer Historyを有効化してよいか判定する
□ 業務用PCと私用PCが分かれているか（分かれていない場合は私用の閲覧まで記録される点に注意）
→ YES: 対象アプリを絞り込んでからONにする
指示例: 「Computer HistoryをONにするので、対象から除外すべきセンシティブなアプリ・サイトの候補を一緒に洗い出して」

□ 会社のセキュリティポリシー・情報管理規程で、操作ログの外部送信に制限はないか
→ YES: 情報システム部門・上長に事前確認してから有効化する
指示例: なし（社内確認が先）

□ Business/Enterpriseプランで、管理者権限を持っているか
→ NO: 管理者にComputer Historyの利用許可を申請する必要がある（権限がないと個人設定だけではONにできない）
002ステップ2：どのタスクをUltrafast（高速処理）候補にするか判定する
□ そのタスクは、状況が数秒〜数分単位で変化する場面か（障害対応・市況変化・接客中の会話等）
→ YES: 高速処理の価値が大きいタスクの候補（本キット「爆速タスク発注文50選」参照）

□ そのタスクは、一晩バッチ処理で足りている（翌朝の確認で十分）か
→ YES: 無理に高速化する必要は薄い。コスト・料金が判明してから検討で十分

□ そのタスクの遅延が、機会損失（離脱・クレーム）に直結するか
→ YES: 経営インパクトが大きい候補として優先的にリストアップしておく
指示例: 「うちの業務の中で、対応が数秒遅れることで機会損失が起きそうな場面を一緒に洗い出して」
003ステップ3：プライバシー・情報管理上のリスクを最終確認する
□ Computer Historyで記録される内容（クリック・タイピング・アプリ切り替え）に、顧客の個人情報・機密情報が含まれる作業はないか
→ YES: その作業をしている時間帯だけ、一時的にOFFにする運用を検討する

□ 48時間の自動削除で足りるか、それより早く消したい情報を扱う作業はないか
→ YES: 該当作業の直後に手動で該当時間帯の履歴を削除する運用にする

□ Ultrafastの料金・一般提供条件がまだ未発表であることを、導入検討メンバー全員が認識しているか
→ NO: 「現時点は限定プレビュー段階で、料金未定」であることを共有してから検討を進める

補足: Ultrafast mode・Computer Historyはいずれも2026年8月時点でプレビュー・限定提供の機能です。本チェックリストの判定結果は導入の目安であり、最終的な可否は必ず公式サイトの最新情報・自社のポリシーで確認してください。
