  → YES: MiniMax H3公式ブログでApplicable Territoryの最新条件を必ず確認する
  → NO: 通常の商用利用条件（上記2,000万ドルの壁）だけ確認すればよい
004ステップ4：API利用時のコストを試算する
□ どのリージョンから使うか決めているか？
  → YES: 東京等のリージョンはシンガポールより約17.5%安い場合がある。料金表で最新の単価を確認する
□ Web検索・画像検索などのツール呼び出しを併用する予定か？
  → YES: ツール利用は別課金（例: Web検索$10/1,000回）になる場合がある。合算した見積もりを作る
□ 月間の想定トークン量（入力・出力）を概算できているか？
  → YES: 入力・出力それぞれの単価×想定量で、月額の目安を先に出しておく
005ステップ5：既存の有償モデル（Claude/GPT等）と比較する
□ 高難度の推論・大規模リポジトリの改修が中心のタスクか？
  → YES: 現時点ではQwen3.8-Maxよりも既存の上位モデルに分がある可能性が高い。既存モデルを継続する
